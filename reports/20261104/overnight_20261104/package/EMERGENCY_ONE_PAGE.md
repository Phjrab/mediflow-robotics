# 현장 비상 정지·중단 한 장

현재 무인 준비는serial중단상태다. shoulder_pan토크1만관측됐고나머지상태는미확인이다. 자동토크OFF·Goal HOLD·전원조작은하지않았다. 현장에사람이오기전에는live를시작하지않는다.

| 상황 | 현장 조치 | 뒤에 확인할 것 |
|---|---|---|
| 예상밖움직임·접촉·끼임·정지불응 | 소프트웨어응답을기다리지말고준비된모터전원차단수단을사용 | 전원차단뒤팔이처질수있으므로시험전낙하영역을비우고지지대를준비 |
| 정상종료/실험중단 | Ctrl+C. 현재코드가종료하고포트를해제했는지확인 | Ctrl+C는토크OFF를의미하지않음 |
| GPU/카메라호출이멈춘상태 | Ctrl+C반응을즉시정지수단으로믿지않음 | 동기추론중신호처리지연가능. 위험하면물리전원차단 |
| 온도/부하/통신/카메라fault | 새정책목표전송중단. 안전확인이없는목표/HOLD추가쓰기를하지않음 | Goal쓰기가OFF토크를다시켤수있던현장관측을고려 |
| 종료뒤토크ON | 손으로팔을억지로돌리지않음. 팔/물체를안정된지지대에받침 | 현장운영자가별도승인된해제절차를수행. 이번무인세션에서는해제하지않음 |

움직이는팔아래나관절틈에손을넣어받치지않는다. 전원을끊어야할상황과정상적인토크해제를구분한다. 케이블/USB만빼면모터전원이꺼진다고가정하지않는다.

현재v4는독립하드웨어정지버튼감시/RobotController단일경로/독립watchdog검증이완료되지않았다. 예외시HOLD도통신실패로전송되지않을수있고,반대로토크상태가OFF이면Goal쓰기자체가활성화를유발할수있다. 성공적인mock이나offline오차를비상정지검증으로대체하지않는다.

저장기록과포트점유만읽는안전한명령:

```bash
python3 -B -m json.tool ~/nov_live_prep_20261104/SERIAL_STOP.json
```

```bash
sudo fuser -v /dev/serial/by-id/usb-1a86_USB_Single_Serial_5AE6058306-if00
```

PID가있으면다른도구로동시에열지않는다.프로세스강제종료/서비스재시작/중단파일삭제로다음단계를강행하지않는다.
