# Jetson SmolVLA dry-run 실제 실행 결과

판정: 파란 바구니 task의 관측→전처리→정책 action chunk→후처리→CSV 기록 1회가 정상 종료했다(exit0). 정책 목표 전송0회이며 live는 실행하지 않았다. 로봇 성공률 또는 G5/G6 통과 결과가 아니다.

## 실제 수행

- 직접 SSH로 기존 모델·보정 해시/근거 파일과 포트 비점유를 확인한 뒤, v4에 --dry-run을 명시하여 실행했다.
- task: `Put medicine bottle A into the blue basket`.
- 체크포인트: `~/smolvla_model/pretrained_model`. 저장된 전처리·후처리를 사용했다.
- 10초 제어 구간 상한과 별도로 외부180초 타임아웃을 두었다. 타임아웃 없이 exit0으로 끝났다.
- 에피소드 녹화나 데이터셋 수정은 하지 않았다. 출력은 새 결과 폴더에 CSV와 시작 이미지3장만 저장했다.
- Jetson 결과 폴더: `~/smolvla_agent_dry_20261104_234610`.
- 검수용 CSV와 PNG만 이 문서 옆의 같은 이름 폴더로 복사했다. 원본은 보존했다.

## 한계·미실행

- 이번 실행의 모델 추론은1회다. 반복 latency p50/p95, GPU 최대 메모리, 장시간 카메라 안정성은 측정하지 않았다.
- 50step을30Hz로 소비하는 명목 시간은1.667초로, 이번 추론3.030초보다 짧다. 실제 실행 속도는 NOT_RUN이며 동기 제어에서 추론 중 HOLD 구간이 생길 수 있다.
- 다음 단계는 현장 안전 확인을 거친 별도 첫 live 시험이다. 사용자 지시대로 아직 실행하지 않았다.
- 학습·녹화·정책 모터 전송·live·push는 NOT_RUN이다. 모델/학습 데이터/보정/LeLab/SDK/정책 코드는 이번 dry-run 작업에서 수정하지 않았다.
- 종료 시 별도 토크OFF를 하지 않았다. 마지막 모터 상태 읽기는6개ON이며, 이 실행은 상시 온도 모니터가 아니다.

