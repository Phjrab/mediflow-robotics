# SmolVLA 20,000스텝 지시 비교

동결 학습 116회와 평가 21회를 유지했다. Chosun RTX 3060에서 학습 완료 체크포인트 `765908e3ccb3…`를 불러왔다. 평가 21회마다 기록의 그리퍼 닫힘 바로 다음 프레임 하나를 골랐다. 각 장면의 640×480 RGB 세 장과 관절 상태는 기존 ACT 사전 평가와 SHA-256 및 수치로 대조했다.

장면마다 빨강·초록·파랑 세 명령을 넣었다. 세 번 모두 같은 초기 노이즈 텐서를 사용했고 색상 토큰열이 서로 다른지 확인했다. 체크포인트에 저장된 CUDA AMP와 10회 디노이징으로 한 번에 50개 목표 자세를 얻었다. 63회는 21개 장면에서 반복 측정한 수다.

## 방향 일치

| 조건 | 각 묶음의 50번째 행동 | 마지막 10개 평균 | 입력 자세 대비 이동 |
|---|---:|---:|---:|
| 전체 명령 | 53/63 | 49/63 | 52/63 |
| 기록색 명령 | 18/21 | 17/21 | 18/21 |
| 다른 색으로 변경 | 35/42 | 32/42 | 34/42 |
| 파랑 명령 전체 | 19/21 | 18/21 | 21/21 |
| 파랑 기록의 파랑 명령 | 6/7 | 6/7 | 7/7 |
| 비파랑 기록의 파랑 명령 | 13/14 | 12/14 | 14/14 |

50번째 행동의 팔 5축을 학습 시연의 같은 상대 시점 색별 중심과 비교했다. 관절별 거리는 학습 시연의 표준편차로 정규화했다. 참조는 학습 중 닫힘·놓기와 50개 행동 창을 확인한 108회(빨강 38, 초록 33, 파랑 37)다. 동일 분류기는 기록된 평가 시연의 행동 20/21, 학습 시연을 하나씩 기준에서 제외했을 때 95/108을 기록색으로 분류했다.

파랑 요청으로 바꾼 빨강 기록은 6/7, 초록 기록은 7/7이 파랑 방향으로 분류됐다. 비파랑 14회에서 기록색 명령 대비 50개 행동의 평균 변화는 팔 3.143°, 그리퍼 1.944점이었다. 전체 63회 중 4회에서 1·2위 거리의 상대 차이가 10% 이하였다. 비파랑→파랑에서는 2/14회가 해당했다. 시연 자체에서도 50개 창 안에 놓기 동작이 있었던 회차는 0/21이었다. 이 결과는 닫힘 직후 50개 목표 자세의 관절 방향을 설명하며 실제 도착이나 놓기 성공은 측정하지 않았다.
