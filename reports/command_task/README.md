# SmolVLA가 닫힘 직후 바구니 명령에 반응하는가

공정 비교용 SmolVLA에서는 관측을 고정하고 명령만 바꿨을 때 42건 중 35건에서 변경한 색의 초기 궤적이 나왔다. 빨강·초록 장면에 파랑을 요청한 경우는 13/14였다. **바구니 단어가 초기 방향 선택에 영향을 준다는 오프라인 근거**다. 50개 행동 안에 시연의 놓기 시점이 들어온 회차는 0/21이어서 실물 투입이나 최종 목적지 도착은 이 시험으로 판정할 수 없다.

## 판정 방식과 한계

사람 시연에서 검출한 닫힘의 바로 다음 프레임 하나를 고정했다. 입력은 같은 순간의 손목·천장·사선 RGB와 팔 상태다. 색 단어만 바꿨고 같은 장면의 세 명령에는 같은 초기 노이즈를 사용했다. 10회 디노이징 후 생성된 **실제 기본 묶음 50개**의 마지막 팔 5축을 같은 상대 시각의 학습 궤적 색 중심과 비교했다. 30fps 기준 약 1.67초이며 ACT의 기본 묶음(100개, 약 3.33초)과 관측 시점은 같지만 판정 시계는 다르다.

색 중심 계산에는 학습 시연만 사용했다. 50번째 행동 기준으로 시연 정답 자체는 20/21, 한 회차를 뺀 학습 시연 분류는 95/108이었다. 주 판정에 근소한 차이가 있으면 모델 행동을 실제 공간의 바구니 도착으로 해석하지 않는다. 이전 보고서의 SmolVLA 교체 지시 12/42는 시연 투입 직전 창을 평가했다. 이번 35/42와 시점과 채점 정의가 다르다. [이전 평가](../model_compare/COMPARE.md)

### 두 종류의 입력 대조

지시를 교체한 결과가 요청 색과 일치하더라도 원래 예측부터 그 색이었을 수 있다. Jetson의 42건 중 **원래 예측과 방향이 달라지면서 새 지시 색에 맞은 경우**는 공정본 32건, 배포본 31건이었다. 이미 그 색으로 예측해 방향 변화 없이 일치한 경우는 각각 3건, 2건이었다.

이전 ACT+지시는 같은 재구성 영상의 비파랑 14개 장면에서 파랑 지시에 따른 파랑 방향이 0회였다. 공정 SmolVLA에서는 13회였다. 두 시험은 같은 관측에서 출발하지만 각 정책 기본 묶음의 끝(100번째와 50번째)을 사용하므로 도착률 비교에는 쓸 수 없다. [ACT 단일 프레임 시험](../model_compare/act_preflight/README.md)

기존 ACT 시험과 같은 재구성 영상에서 21개 장면을 추출했다. 공정본은 RTX 3060의 저장 CUDA 혼합 정밀도로 실행했다. 이 결과에서 세 색 명령을 모두 맞힌 장면은 14/21이었다. 빨강·초록 장면의 명령을 파랑으로 바꿨을 때 기록 명령 대비 50개 예측의 평균 변화는 팔 5축 3.143°, 그리퍼 1.944점이었다. 지시를 바꿀 때 실제 목표 자세가 변한다는 측정도 방향 분류와 함께 남겼다. [공정본 세부 결과](smolvla/README.md)

같은 재구성 영상으로 배포본을 Windows CPU에서 CUDA 혼합 정밀도 없이 재검사했다. 공정본 실험과 디코딩한 RGB 63/63, 상태 21/21, 노이즈 21/21이 일치했다. 배포본은 교체 지시 33/42, 비파랑 장면의 파랑 지시 11/14였다. 두 모델을 같은 장치·정밀도로 비교할 때는 아래 Jetson 결과를 사용한다. [배포본 방향 판정](historical_smolvla_cpu/direction.json)

별도 대조에서는 두 모델을 같은 Jetson에서 보존 원본 영상, 같은 부동소수점 노이즈 배열, 동일한 저장 FP16 설정으로 실행했다. 두 모델 간에 63개 RGB 해시와 각 21개의 관절 상태·노이즈 해시가 모두 일치했다. Jetson 원본과 재구성 영상 사이에는 회차·프레임·상태가 같지만 디코딩한 RGB 해시 일치는 0/63, 같은 공식으로 생성한 노이즈 해시 일치는 0/21이었다. 서로 다른 입력 행을 합산하지 않는다. 배포본이 이미 이 회차를 학습했다는 점도 모델 간 우열 판정을 제한한다.
