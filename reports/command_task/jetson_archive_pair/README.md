# Jetson 저장 영상의 SmolVLA 3색 지시 비교

같은 Jetson 저장 영상에서 21회 시연의 실제 닫힘 직후 프레임을 골랐다. 두 모델은 관측마다 같은 3카메라 RGB, 6축 관절 상태와 난수 배열을 사용해 빨강·초록·파랑 지시에 각각 50개 행동을 출력했다. RGB 63개, 상태 21개, 난수 21개의 SHA-256이 모델 간에 모두 일치했다. 두 모델 모두 Jetson Orin, PyTorch 2.8.0의 저장 CUDA FP16 AMP, 10회 denoising을 사용했다. [입력 검증](pair_verification.json)

| 모델 | 전체 요청 일치 | 원래 지시 | 교체 지시 | 파랑 요청 | 비파랑 → 파랑 | 원래 파랑 |
|---|---:|---:|---:|---:|---:|---:|
| 기존 배포 b84 | 52/63 | 19/21 | 33/42 | 17/21 | 11/14 | 6/7 |
| 최종 SmolVLA 20k | 53/63 | 18/21 | 35/42 | 19/21 | 13/14 | 6/7 |

일치는 50번째 행동의 팔 5축 목표를 학습 116회에서 계산한 색별 참조 방향으로 분류한 값이다. b84는 평가 시연을 학습에 사용한 비교 기준이다. Jetson과 Chosun의 실험은 회차·프레임 번호·관절 상태가 같았다. 정준 영상의 RGB 해시는 Jetson 원본 아카이브와 0/63 일치했고, 같은 seed 공식으로 만든 Chosun 난수 해시도 Jetson과 0/21 일치했다.
