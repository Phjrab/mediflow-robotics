# 기본 ACT의 이른 닫힘과 시연 손목 영상

16프레임씩 예측한 기존 평가에서 파랑 7회 중 **6회가 시연보다 먼저 닫혔다.** 이른 6회에서 약통 마커는 시연 닫힘 시점에 비해 오른쪽 4회, 왼쪽 2회에 보였다. 98번은 19프레임 일찍 닫히며 오른쪽 15.50 px, 136번은 20프레임 일찍 닫히며 왼쪽 8.25 px였다. 이른 닫힘만으로 한쪽 방향의 파지 편향을 정할 수 없다.

## 기존 16프레임 평가의 회차별 측정

시간차는 (예측 닫힘 프레임 − 시연 닫힘 프레임) / 30이다. 두 x좌표는 **같은 시연 영상**에서 측정했다. 640×480 손목 영상에서 약통 뚜껑 ArUco 마커 9번의 네 꼭짓점 x평균을 썼으며, Δx가 양수이면 예측 시각의 마커가 시연 닫힘 시각보다 오른쪽에 보였다. [픽셀 판독 코드](../../lerobot_training/model_compare/wrist_close_pixels.py)

## 재생 길이를 바꿨을 때

아래 셀은 **예측 닫힘 − 시연 닫힘 (프레임) / Δx (px)**다. H는 저장 관측을 다시 넣기 전까지 사용하는 행동 수다. 같은 회차를 반복 평가했으므로 네 열의 표본을 합산하지 않았다. 빈 픽셀값은 해당 시각에 마커가 검출되지 않은 경우다. [검증된 25·50·100프레임 재생](act_preflight/replay_horizons.json) · [전체 측정 원자료](act_blue_close_correlation.json)

| 회차 | H16 | H25 | H50 | H100 |
|---:|---:|---:|---:|---:|
| 97 | −3 / +0.25 | 0 / 0 | 0 / 0 | +7 / +22.25 |
| 98 | −19 / +15.50 | −38 / +9.25 | −84 / 미검출 | −122 / 미검출 |
| 103 | −4 / −0.25 | −1 / −0.75 | −1 / −0.75 | +28 / +3.25 |
| 105 | −2 / +3.00 | −3 / +3.00 | −23 / 미검출 | −12 / +13.25 |
| 109 | −6 / +1.75 | +2 / +2.25 | +2 / +2.25 | −45 / 미검출 |
| 121 | +3 / −0.50 | +4 / −2.00 | +7 / +0.75 | −76 / 미검출 |
| 136 | −20 / −8.25 | −3 / +3.50 | +9 / +4.50 | +25 / +5.00 |

| 재생 길이 | 이른 닫힘 / 전체 | 픽셀 매칭 / 전체 | 부호 포함 Pearson r / Spearman ρ | 절댓값 Pearson r / Spearman ρ |
|---|---:|---:|---:|---:|
| H16 | 6/7 | 7/7 | −0.170 / 0.000 | +0.886 / +0.518 |
| H25 | 4/7 | 7/7 | −0.890 / −0.847 | +0.943 / +0.775 |
| H50 | 3/7 | 5/7 | +0.767 / +0.900 | +0.692 / +0.821 |
| H100 | 4/7 | 4/7 | −0.646 / −0.800 | −0.973 / −1.000 |

부호 포함 상관은 예측이 빠르거나 늦을 때 마커가 어느 쪽에 보였는지 비교한다. 절댓값 상관은 시간차가 큰 회차에서 영상 위치 차이의 크기도 컸는지 비교한다. H16에서 두 큰 조기 오차가 서로 반대쪽에 있어 부호 포함 Pearson r은 −0.170이지만 절댓값 r은 +0.886이다. H100에서는 가장 일찍 닫힌 세 회차(98·109·121)의 마커가 모두 미검출됐다. 남은 네 쌍의 상관은 큰 조기 오차 사례를 대표하지 않는다. [계산 코드](../../lerobot_training/model_compare/act_close_correlation.py)

모델은 실제로 움직이지 않았으며, 영상은 시연자의 동작을 보여 준다. 이 값으로 실제 ACT 그리퍼와 약통 사이의 수평 파지 오차, 이른 닫힘의 원인, 실물 성공 가능성을 정량화할 수 없다.

**실행기 변경 제안.** 우선 기록에서 약통이 두 손가락 사이에 들어온 프레임을 표시하고, 닫힘 명령과의 시간차를 직접 측정한다. 이후 보류 조건을 시험한다면 좌·우 한쪽으로 고정 오프셋을 더하는 방법보다, 시야에서 약통과 양쪽 손가락을 함께 확인했을 때의 짧은 닫힘 보류를 오프라인에서 먼저 비교한다. 이번 변경에는 닫힘 보류나 좌우 보정을 추가하지 않았다.
