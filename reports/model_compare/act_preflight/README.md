# ACT 파랑 작업 사전 평가

2026-11-25 KST. Chosun RTX 3060에서 원래 동결 평가 분할 21회(색별 7회)를 저장 RGB로 재생했다. 기본 ACT는 40,244스텝, ACT + 지시는 40,163스텝 체크포인트다. 이 실험에서는 학습이나 장치 동작을 수행하지 않았다.

## 시연 닫힘 직후 단일 추론

기존 닫힘 규칙으로 시연 action의 닫힘 프레임을 잡고 그 다음 프레임인 `close_true + 1`을 입력했다. 640×480 원본 세 카메라의 RGB과 같은 프레임의 시연 관절 상태를 사용했다. 각 색 조건은 같은 입력을 공유한다. 기본 ACT에는 색 조건이 없으며, 지시 ACT의 파랑 강제에서는 원래 6축 자세를 유지하고 one-hot 3값만 바꿨다. 두 모델 사이에서도 같은 원본 RGB 세 장을 SHA-256으로 대조했다.

각 회차에서 ACT는 100개 목표 자세(30 Hz 기준 3.33초 분량)를 한 차례 출력했다. **100번째 행동의 팔 5축**을 출발점 기준 정확히 같은 상대 시점의 학습 시연 색별 중심과 비교했다. 거리는 학습 행동의 5축 표준편차로 나눈 축별 RMS다. 마지막 10개 평균 종점, 입력 자세를 뺀 상대 이동, 시연에서 놓기 직전 10개 평균 자세를 기준으로 한 별도 분류도 함께 남겼다. 학습 116회 중 닫힘·놓기와 100프레임 창을 모두 확인한 108회(빨강 38, 초록 33, 파랑 37)가 기준에 포함됐다. 학습 시연의 회차 제외 교차검증(leave-one-out)은 해당 회차를 중심과 스케일에서 제외했다.

1·2위 거리를 `d1`, `d2`라 할 때 상대 마진 `(d2-d1)/max(d2, 1e-12)`이 0.10 이하이면 모호로 표시했다. 입력 대비 마지막 10개 평균의 정규화 이동 RMS가 0.10 미만이면 저이동으로 표시했다. 모호·저이동도 전체 분모에 포함한다. 이 규칙은 관절 궤적의 유사도를 색 방향으로 판정한다. 기록 자체도 이 100개 창에서 놓기가 관찰된 경우는 18/21회였으며, 물체 도착이나 실제 성공은 현장에서 확인해야 한다.

| 입력 조건 | 정확한 100번째 행동 | 마지막 10개 평균 | 입력 대비 이동 | 놓기 직전 기준 |
|---|---:|---:|---:|---:|
| 기본 ACT, 기록 조건 | 21/21 | 21/21 | 21/21 | 21/21 |
| ACT + 지시, 기록색 지시 | 21/21 | 21/21 | 21/21 | 21/21 |
| 기본 ACT, 파랑 요청 | 7/21 | 7/21 | 7/21 | 7/21 |
| ACT + 지시, 파랑 요청 | 7/21 | 7/21 | 7/21 | 7/21 |
| 평가 시연의 기록 행동 | 18/21 | 18/21 | 17/21 | 19/21 |
| 학습 시연 회차 제외 | 94/108 | 95/108 | 100/108 | 106/108 |

기록 조건에서는 기록색, 파랑 요청 행에서는 파랑으로 분류된 회차를 세었다. 100번째 행동 기준 두 모델 모두 비파랑 14회 중 파랑으로 분류된 경우가 0회였다. 기본 ACT의 행동은 상태와 영상이 같을 때 파랑 요청 전후 모든 축에서 동일했다. 지시 ACT는 빨강 기록 7회 중 6회가 초록, 1회가 빨강으로 분류됐다. 초록 7회와 파랑 7회는 각각 기록색을 유지했다. 지시 ACT의 파랑 강제에서 2/21회가 거리 마진 기준으로 모호했다. 두 모델 모두 미세 이동으로 분류된 회차는 없었다. 마지막 10개 평균으로 변경해도 파랑 전환은 0/14회였으며, 빨강 7회 중 5회가 초록이었다.

**100번째 행동의 방향 분포**. 각 칸은 빨강 / 초록 / 파랑으로 분류된 회차 수다. 기본 ACT에는 색 입력이 없어 같은 장면의 파랑 요청에서도 기록 조건과 동일한 행동이 나왔다.

| 녹화 장면 | 기본 ACT | ACT + 기록색 지시 | ACT + 파랑 지시 |
|---|---:|---:|---:|
| 빨강 7회 | 7 / 0 / 0 | 7 / 0 / 0 | 1 / 6 / 0 |
| 초록 7회 | 0 / 7 / 0 | 0 / 7 / 0 | 0 / 7 / 0 |
| 파랑 7회 | 0 / 0 / 7 | 0 / 0 / 7 | 0 / 0 / 7 |

따라서 조건을 바꿔도 항상 파랑으로 움직인다고 판단할 근거가 없다. 장면과 관절 자세에 담긴 정보 중 어느 쪽이 방향을 결정했는지는 이번 시험에서 따로 분리하지 않았다.

## 기본 ACT의 재추론 간격

기본 ACT 40,244스텝의 출력은 매번 100개다. 회차 프레임 0부터 시연 관측을 25·50·100프레임 간격으로 다시 입력하고 각 출력의 앞 25·50·100개를 이어 붙였다. 같은 호출 프레임에 대해서는 동일한 예측을 세 조건이 공유한다. 시연 관측을 재생했으므로 로봇 동작에 따른 관측 변화는 반영되지 않는다. 닫힘 시각 MAE는 시연과 예측 모두에서 닫힘을 찾은 회차 기준이다. 닫힘 자세·그리퍼 오차는 시연의 닫힘 프레임에서 읽었다.

| 재추론 간격 | 파랑 닫힘 시각 MAE | 파랑 닫힘 자세 MAE | 파랑 전 구간 그리퍼 MAE | 파랑 닫힘 프레임 그리퍼 MAE | 전체 닫힘 시각 MAE |
|---|---:|---:|---:|---:|---:|
| 25개 (0.83초) | 0.243초 (7/7) | 2.213° | 3.000점 | 7.112점 | 0.351초 (21/21) |
| 50개 (1.67초) | 0.600초 (7/7) | 3.703° | 3.536점 | 8.392점 | 0.527초 (21/21) |
| 100개 (3.33초) | 1.500초 (7/7) | 5.983° | 4.550점 | 7.522점 | 1.237초 (21/21) |

25개 간격이 파랑 회차의 닫힘 시각, 닫힘 자세, 전 구간 그리퍼 오차에서 가장 작았다. 다만 98번 회차에서는 25개 간격에서도 38프레임(1.267초) 일찍 닫혔다. 회차별 시연·예측 닫힘 프레임, 초, 방향, 각 축 오차는 [재추론 기록](replay_horizons.json)에 있다.

## Jetson에서 같은 180초 동안 비교

기본 ACT가 매번 생성한 100개를 물리 단위로 복원한 뒤 앞에서 25·50·100개를 취했다. 세 조건 모두 같은 저장 RGB와 같은 가중치에서 30Hz·0.5배속으로 실행했다. 고유 행동 수는 보간에 실제 사용한 서로 다른 행동 번호를 센다. 이 모의와 위 표의 오프라인 재추론은 측정 대상이 다르다. 위 표는 시연 시간 간격마다 새 관측에서 예측한 오차이고, 아래 표는 실제 시간으로 legacy 버퍼가 대기한 시간이다. [Jetson 실행별 결과](jetson_chunks.json)

| 실행 묶음 | 고유 행동/초 | 누적 대기 | 평균 모의 제어 Hz | 파랑 닫힘 시각 / 자세 MAE |
|---|---:|---:|---:|---:|
| **25개** | **15.000** | **0초** | 29.863 | **0.243초 / 2.213°** |
| 50개 | 15.000 | 0초 | 29.865 | 0.600초 / 3.703° |
| 100개 | 15.006 | 0초 | 29.864 | 1.500초 / 5.983° |

**대기 없는 가장 짧은 묶음은 25개다.** 이전 전체 모델 비교의 ACT 닫힘 오차 0.271초·1.533°는 모든 모델의 평가 간격을 16개로 고정해 얻은 값이다. 100개를 끝까지 사용했을 때의 오차는 이번 표의 1.500초·5.983°다. [닫힘 시각과 손목 화면의 위치 관계](../ACT_CLOSE_CORRELATION.md)

## 파랑 전용 재학습안

동결 train의 파랑 37회(16,269프레임)만 사용하고 학습 통계도 그 37회에서 산출한다. 기본 ACT 구조, 배치 8, 100개 출력, 원래 seed를 유지한 별도 실행을 기존 체크포인트와 비교한다. 중간 선택용 분할은 37회 내부에서 회차 단위로 두고, 파랑 평가 7회는 마지막 비교에만 사용한다. 내부 검증 단계의 통계는 내부 학습 회차에서만 산출한다. 학습 스텝을 선택한 뒤 37회 전체로 재학습할 때는 37회 전체의 통계를 사용한다.

기본 ACT의 Chosun 실측은 40,244스텝에 7시간 58분으로 검증·저장을 포함해 스텝당 약 0.713초였다. 같은 비율을 가정하면 5,000스텝은 약 59분이다. 원래 학습 프레임 수의 30.3%인 파랑 분량에 비례한 약 12,190스텝은 약 2시간 25분이다. 이 값은 계획 추정이며, 실제 시간은 검증·저장 구성과 장치 상태에 따라 달라진다.

## ACT dry-run과 기본 경로 복귀

실험 브랜치의 `so101_vla/live/run.sh`에서 `--policy act`를 선택한다. 기본 ACT 40,244스텝의 가중치와 설정, 입출력 정규화 파일의 SHA-256이 모두 일치해야 한다. 기본 출력은 100개이며, 권장 시험에서는 `--n-action-steps 25`를 명시한다. 홈 점검과 legacy 목표 처리에는 기존 코드를 사용한다. 조인트 피드백과 목표 전달은 메모리의 모의 팔이 담당한다.

다음 명령에서 `ACT_CHECKPOINT`는 기본 ACT 40,244스텝의 `pretrained_model` 디렉터리다. 실행 중인 정렬 서비스가 게시한 손목·천장·사선 JPEG 세 장의 해상도와 신선도를 검사한다. 멈췄거나 1초 이상 오래된 게시물은 새 추론에 쓰지 않는다.

```bash
bash live/run.sh --policy act --mode legacy --dry-run --act-checkpoint "$ACT_CHECKPOINT" --act-alignment-preview --n-action-steps 25 --speed 0.5 --duration 60
```

되돌리려면 평소 명령에서 ACT 전용 인자를 전부 빼면 된다. 정책 선택은 한 번의 실행에만 적용되며, 기본값과 `--policy smolvla`는 모두 기존 SmolVLA 실행기로 들어간다. 이번 ACT 경로는 명시적인 dry-run에서만 열리고 `--live` 요청은 하드웨어 준비 전에 종료된다.

**쓰기 범위 검토.** 기존 legacy의 시작·복구 패킷은 대상과 값을 검사한 `Torque_Enable`(주소 40)·`Goal_Position`(42)만 전송한다. 그리퍼의 `Max_Torque_Limit`(16)·`Torque_Limit`(48)는 해당 실행기에서 읽기 검사만 한다. ACT 경로에는 시리얼 열기 차단을 두었고, 보정·PID·가속도 및 토크 한계 쓰기를 추가하지 않았다. [기존 패킷 검사](../../../so101_vla/live/stream_live.py) · [ACT 분기와 모의 입출력](../../../so101_vla/live/act_dry.py)
