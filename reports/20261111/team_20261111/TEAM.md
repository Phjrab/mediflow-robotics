## 이번 문제

홈 화면은 홈 평균과 ±2도(그리퍼 ±2점)만 비교했다. 실제 VLA 시작 검사는 원시 위치 범위도 확인한다. 팔꿈치 현재 3084틱은 홈 평균과 약 +0.195도로 홈 정렬은 통과하지만, 명령 상한 3082틱과 시작 측정 여유 1틱을 합친 3083틱보다 높아 시작에서 멈춘다. 최근 실행은 0스텝, 목표 전송 0회였다.

수정 목표는 홈 정렬과 VLA 시작 위치 조건을 같은 원천 기준으로 표시하는 것이다. 기존 시작 허용범위, 목표 범위, 온도, 토크, 모델 조건은 변경하지 않는다. 위치 조건 통과를 전체 live 준비 완료로 표시하지 않는다. raw ticks 누락·오래된 관측·기준 로드 실패는 미확인으로 표시한다.

## 공동 작업 규칙

- 담당은 자신의 파일만 수정한다. 기존 파일 수정 전 날짜가 있는 백업을 만든다.
- Jetson 배포와 서비스 조작은 총괄만 한다. 담당은 SSH·serial·카메라·모델 실행을 하지 않는다.
- 실제 모터 동작은 이번 작업에 포함하지 않는다. 원본 데이터, 체크포인트, 보정 파일과 모터 보정값은 보존한다.
- push는 하지 않는다. 비밀번호·토큰을 파일이나 로그에 남기지 않는다.
- 결과에는 완료 내용, 변경 파일, 검사 명령과 결과, 남은 문제, 다음 담당에게 필요한 내용을 적는다.
- 기준 JSON/JS/Python의 경계값 판정을 독립 검증한 뒤 배포한다. 실행기를 다시 돌려 억지로 통과시키지 않는다.

## 첫 작업 순서

1. 실행기 담당: 기존 판정 보존, 순수 판정 모듈, 근거를 포함하는 JSON exporter, 오류 메시지 개선.
2. 관제 담당: 동일 JSON을 사용하는 홈 화면, 6축 raw 틱·범위·미확인 상태 표시.
3. 평가 담당: 경계값/결측/오래된 관측 모의 테스트와 Python·JS 판정 일치 확인.
4. 총괄: 설치 파일 확인 → 백업 → 배포 → 실제 웹 표시와 읽기 전용 검증 → 결과 기록.
