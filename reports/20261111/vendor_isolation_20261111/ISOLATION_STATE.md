# 최신 배선 상태: 제어보드 → 손목 회전 → 그리퍼, DC ON 후 읽기 종료

2026-11-12. 사용자가 상류 검사 후 DC OFF를 확인하고 배선을 변경한 뒤 전원선을 다시 연결했다고 알렸다. 사용자가 말한 위치 번호 2·3을 실제 모터 ID로 추정하지 않았다. 실제 READ 조회에서 ID5·6만 응답했고 ID1~4는 정상 시간 만료·수신 0·OS 오류 0의 NO_RESPONSE_UNVERIFIED였다. 따라서 지금 수행한 검사는 손목 회전·그리퍼 두 모터 구성이다. 이전 상류 연결 안내를 그대로 적용하지 않는다.

동일 선택 도구로 ID5·6 30Hz / ID6 180Hz / ID6 전압-온도-전압 60Hz를 각20초 읽었다. 큰 급변(중앙값+8°C)은0회였으나 그리퍼30→34→30°C가 30Hz와180Hz 각각1회 남았다. 최대34°C. 완전 정상이나 수리 완료로 판정하지 않는다. 앞선 상류ID1의28→37→28°C와 함께 정확한 공통 원인은 미확인이다.

성공 READ 8,548쌍 독립 검산, 목표·토크·설정 쓰기0. 마지막 ID5=28°C/ID6=31°C, 둘 다12.3V·토크OFF. 포트 비점유, 모든 진단 종료, LeLab inactive/Astra active, SSH/SCP 종료. DC·배선은 검사 후 원격 변경하지 않았다. 다음 OFF 확인 전까지 마지막 상태는 DC ON이다. 상세는 TWO_NODE_RESULT.md 및 wrist_group_check_crexxfk5/를 따른다.

다음 현장 조작은 DC OFF 확인부터 한 단계씩 안내한다. 다른 전원·테스터기는 없으며, 어깨 쪽 커넥터를 빼기 어렵다는 제한은 유지한다. 선은 양쪽 연결 위치와 어느 끝인지 말한다. 손목/팔꿈치라는 사용자 명칭 또는 사용자 위치 숫자를 모터 ID와 같다고 가정하지 않는다.

## 이전 배선 상태: 제어보드 → 팔꿈치 쪽, DC ON 확인 후 읽기 종료

2026-11-12 최신 운영자 진술과 실제 측정: 사용자가 손목–팔꿈치 선의 손목 끝을 제어보드로 옮긴 구성을 먼저 검사하도록 요청했다. 같은 선 반대쪽은 팔꿈치 쪽에 연결한 구성으로 DC ON 및 텔레옵 OFF를 확인했다. 원래 어깨–보드 선은 보드 끝 분리, 그리퍼–손목 선은 손목 끝 분리 상태다. 추가로 어깨 커넥터를 빼지 않는다. 이후 사용자 확인 전까지 DC를 OFF로 기록하지 않는다.

실제 응답 ID1–4, 토크 모두 OFF. ID5·6은 엄격한 완전 무응답으로 NO_RESPONSE_UNVERIFIED. 각 20초의 4축 30Hz / ID4 180Hz / ID4 전압-온도-전압 60Hz 검사 완료. ID1에서 28→37→28°C(35.0ms/31.7ms), 전압 세 표본 모두 12.2V로 급변 재현. 손목 회전·그리퍼를 뺀 연결에서도 남으므로 특정 그리퍼/그 사이 선만 원인으로 지목하지 않는다. 정확한 부품 원인은 미확인.

목표·토크·설정 쓰기 0회. 원문 성공 READ 9,896쌍 독립 검산. 마지막 ID1–4 토크 모두0, 온도28/29/28/28°C, 전압모두12.2V. 포트 비점유, 진단 종료, LeLab inactive/Astra active, SSH/SCP 종료. 최초 수신큐1바이트 송신전 중단과 별도 수동수신(0TX/0RX)을 보존했다. 상세는 UPSTREAM_CHAIN_RESULT.md와 upstream_chain_fsnet7lg/를 따른다.

현재 손목·그리퍼 두 모터 구성 시험은 NOT_RUN. 준비된 ID5·6 도구는 그 구성으로 연결이 확인된 뒤에만 사용할 수 있다. 다음 배선 변경은 DC OFF를 운영자가 확인한 뒤 한 단계씩 안내한다. 케이블은 '어디와 어디 사이에서 어느 쪽을 뺀 끝'인지 말하고 '여분선'만으로 지칭하지 않는다.

## 아래는 이전 배선 상태: 손목↔그리퍼 여분선, DC OFF

최신 운영자 보고 및 교체 후 실제 읽기 결과. 아래 과거 검사 종료 상태와 구별한다.

2026-11-12 후속 운영자 확인: 비교 검사 종료 뒤 팔로워 DC 전원을 분리했다. 손목↔그리퍼 여분선은 유지했고 어깨 및 나머지 배선은 건드리지 않았다. 현재 DC OFF이며 추가 장치 읽기를 실행하지 않는다. 사용자는 다음 현장 작업을 한 메시지에 묶어 자세히 안내받기를 원한다. 이미 완료된 전원 라벨 확인과 손목↔그리퍼 선 교체를 반복시키지 않는다.

운영자가 DC OFF에서 손목↔그리퍼 선의 양끝을 여분선으로 교체한 뒤 DC ON을 확인했다. 어깨 및 나머지 선은 그대로이며, 기존 손목↔그리퍼 선은 양끝 분리 상태로 보관했다. 사진의 그리퍼 쪽은 좌→우 검정/빨강/흰색, 손목 쪽은 위→아래 검정/빨강/흰색으로 보였고, 사진 방향 차이를 구분했다. 사진은 전기적 연속성 시험이 아니다.

같은 바이너리와 같은 세 프로필로 20초씩 비교 완료. 여분선에서도 32→47→32°C 등 급변이 남았다. 목표·토크·설정 쓰기 0회, 11,232 READ쌍 재검증. 마지막 6축 토크 모두 0, 온도 29/30/29/30/29/32°C, 전압 모두 12.2 V, 상태 0. 포트 비점유, 진단 프로세스 없음, LeLab inactive/Astra active, SSH 종료 확인. DC와 여분선 연결은 바꾸지 않았다. 결과는 `WRIST_GRIPPER_CABLE_RESULT.md`를 따른다. 손목↔그리퍼 선 하나의 교체로 해결되지 않았으며 어깨 커넥터 분리는 계속 보류한다.
