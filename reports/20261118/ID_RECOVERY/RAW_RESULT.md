## 재현과 복구

현재 안전한 소프트웨어 재현 명령(모터 시리얼 열기 차단):

```bash
bash ~/so101_vla/live/run.sh --mode raw --dry-run --duration 180
```

실물 버스 정상 확인 후에만 사용하는 실행 형식이다. 이번 작업에서는 둘 다 실행하지 않았다.

```bash
bash ~/so101_vla/live/run.sh --mode raw --live --duration 180
bash ~/so101_vla/live/run.sh --mode legacy --live --speed 0.33 --duration 180
```

옵션 복구는 `--mode legacy`, 코드 복구는 변경 파일 보존 후 `git checkout pre-raw-20261118`이다. 태그로 코드 복구하면 구버전에는 `--mode` 옵션이 없으므로 해당 옵션을 생략한다.
