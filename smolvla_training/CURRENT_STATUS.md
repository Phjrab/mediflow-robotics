**모델·dry-run 검증은 통과했지만, 목표 초기화 실기는 HOLD됐다. live는 진행하지 않는다.**

- 사용자 직접 초기화에서 Goal 패킷1개 송신 후 예상 토크 상태 불일치가 발생했다. 어느 관절의 어떤 값인지는 원래 stop_observed=null 때문에 미확인이다.
- 사용자가 팔을 받치고 follower 전원을 OFF했다고 확인했다. 이후 모터·카메라를 열거나 추론하지 않았다.
- FIELD_STOP과 원본 결과는 그대로 보존했다. 재시도·중단 파일 삭제·과거 live 명령 재사용은 하지 않는다.
- 누락된 관측 기록을 보완했다. 기존 읽기의 값과 단계만 기록하고, 고장 감지 후 추가 읽기·쓰기를 하지 않는다.
- 로컬과 Jetson 각각 관련 모의 테스트49개 통과. SDK 합성 응답4종과 목표 패킷 형식 검사는 별도 통과. 실제 토크 불일치 원인은 아직 미확인이다.
- 이전 추론 지연 개선·dry-run3/3 통과는 그 당시의 결과로 보존한다. 실제 초기화나 VLA 실기 성공의 증거로 쓰지 않는다.
