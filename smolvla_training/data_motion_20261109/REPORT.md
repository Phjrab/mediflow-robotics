## 적용과 검증

- 각도 목표는 실제 전송한 직전 정수 목표에서 2° 및 관절별 속도 상한만큼 이동한다. 그리퍼는 위치점 기준 현재/직전 목표에서 2점 이내를 유지한다. 현재와 활성/예정 목표 차이가 15°를 넘으면 새 목표를 보류한다. 활성 목표 차이가 같은 축에서 25° 초과로 0.5초 지속되면 HOLD한다.
- 보정 가동범위, 팔꿈치 가동범위, 시작 50°C 미만, 실행 55°C 미만, 상태코드 0, 부하·전류 제한과 Ctrl+C는 유지한다. 토크·설정 쓰기 경로는 없다. 모델 원목표, 제한 목표, 실제 SDK 패킷 정수값, 현재 위치, 부하, 전류와 제한 사유를 매 스텝 기록한다. 송신은 서보 수신 확인과 구분한다.
- 팔꿈치가 한 구간에서 1° 이상 명령받고 0.5초 뒤에도 관측 폭이 목표 폭의 50% 미만이면 HOLD한다. 300스텝에는 동일 코드의 50스텝 완료 및 이 기준을 충족한 실측이 필요하다. 관절별 이동 비율은 실제 정수 목표를 각도로 환산한 최대–최소 폭 대비 관측 최대–최소 폭이다. 목표 폭이 1° 또는 1점 미만이면 비율을 계산하지 않는다.
- Windows 모의 265개, Jetson 모의 22개, 저장 궤적 dry-run, 50스텝 파일 검증 모두 종료코드 0. dry-run은 이상적 가상 추종에서 300개, 팔꿈치 고정 조건에서 50개 뒤 HOLD를 확인했다. 실제 송신 0회, 실측 이동 비율 없음. 새 추론·실시간 카메라 사용 없음.
- Jetson 코드 13개 배포. 이전 중단 기록 6개 해시 불변. 이전 코드 백업: `~/v6_process_1793887709179/software_backups_20261109/1794203068101471038`. 롤백 시 저장된 이전 코드와 신규 파일 목록을 기준으로 소프트웨어만 복구하며 중단·실행 기록은 유지한다.
- 현장 50스텝: 명령 전달, 실측 결과 대기. 300스텝·서보 설정 변경·재학습·push: NOT_RUN.
