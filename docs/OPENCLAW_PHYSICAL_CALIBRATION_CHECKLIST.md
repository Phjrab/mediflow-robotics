# OpenClaw + ArUco 물리 보정 체크리스트

작성: 2026-10-05 (KST)

이 문서는 다음 현장 단계에서 필요한 항목을 미리 정리한 것이다. 현재는 어떤
모터 명령도 실행하지 않는다. 기존 LeLab/카메라/ArUco 설정을 초기화하지 않는다.

## 현재 자동 확인 완료

- 천장 raw 프레임에서 작업대 기준 마커 0, 1, 2, 3 검출
- 바구니 마커 4, 5, 6 검출
- A=큰 약통/ID 6, B=중간/ID 5, C=작은/ID 4 매핑
- 현재 배치에서 실제 약통 뚜껑 중심 3개 검출(C/B/A 순서)
- X 표시는 픽업 기준에서 제외
- 안전 정보가 없으면 waypoint 0개로 거부하는 계획기 검증

## 사용자 현장 확인 1: 물체 배치

아래 두 항목만 눈으로 확인한다. 이 단계에서는 로봇 전원을 켤 필요가 없다.

1. 약통이 화면 왼쪽부터 C(작은 것), B(중간), A(큰 것) 순서인지 확인
2. 큰 A 바구니에 ID 6, 중간 B 바구니에 ID 5, 작은 C 바구니에 ID 4가 붙어 있는지 확인

현재는 뚜껑 원 3개의 실제 중심을 찾으므로 X를 쓰지 않는다. 다만 약통 신원은
고정된 C/B/A 좌우 순서를 사용한다. 순서를 바꾸려면 새 약통 분류 모델이나 약통용
고유 마커가 필요하다. 현재 YOLO 모델은 2026-10-05 raw 프레임에서 약통을 하나도
검출하지 못했다.

동기화 RGB-D 진단은 가능했지만 작업대 기준점 rigid-fit RMS가 약 21.1 mm라서
현재 depth 좌표를 파지에 사용하지 않는다.

## 사용자 현장 도움 2: 로봇-작업대 변환

권장 방식은 4~6개의 작업대 점에 그리퍼 TCP를 수동으로 맞추고 각 점의
로봇 관절 상태를 읽는 것이다. 자동 이동은 사용하지 않는다.

- 서로 일직선이 아닌 점 4개 이상
- 작업대 모서리 바로 위가 아니라 충돌 여유가 있는 점
- 모든 점에서 같은 TCP 기준(예: 닫힌 두 손가락 끝의 중앙)
- 각 점마다 ArUco 작업대 XYZ와 FK 로봇 베이스 XYZ를 한 쌍으로 저장
- 보정에 사용하지 않은 별도 점에서 오차를 검증

여기서는 그리퍼 링크 원점이 아니라 실제 파지 TCP 오프셋을 먼저 정해야 한다.
현재 URDF만으로 TCP 위치를 추측하지 않는다.

## 사용자 현장 도움 3: 높이와 범위

다음 값을 실측하거나 매우 느린 수동 조작으로 확인한다.

- `pickup_z`: 약통을 잡는 TCP 높이
- `approach_z`: 약통/바구니 위를 안전하게 지나가는 높이
- `basket_drop_z`: 바구니 안에서 놓는 TCP 높이
- 로봇 베이스 기준 안전한 X/Y/Z 최솟값과 최댓값
- 각 관절의 실제 안전 범위

## 통과 조건

- `T_B_W` 보정 오차를 숫자로 기록
- 독립 검증점 오차가 파지 여유보다 충분히 작음
- 모든 waypoint가 XYZ 및 관절 제한 안에 있음
- IK가 모든 waypoint에서 연속적인 해를 냄
- 모터 전원 없이 생성 경로를 사람이 검수함
- 실제 시험 직전 사용자가 작업공간, 전원차단 준비, 1회 저속 시험을 다시 승인함

이 조건 전에는 OpenClaw에 실행 기능을 추가하지 않는다.

## 2026-10-05 수동 보정 사전 게이트

- 추론: 비활성
- 텔레오퍼레이션: 비활성
- 팔로워 읽기: pan -5.76°, lift -97.36°, elbow 96.57°, wrist flex 45.41°,
  wrist roll -16.40°, gripper 44.49
- 리더 읽기: pan 0.13°, lift -97.93°, elbow 97.58°, wrist flex 44.92°,
  wrist roll -23.47°, gripper 46.40
- 3도 제한 초과: shoulder pan 5.89°, wrist roll 7.08°
- 판정: `START_GATE_REJECTED_WITHOUT_MOTION`

8022 텔레오퍼레이션에 다음 제한을 배포했다.

- 몸체 관절 시작 차이 최대 3도
- 그리퍼 시작 차이 최대 8
- 명령 1회당 상대 목표 최대 1도
- 제어율 30 Hz
- 세션 최대 180초

리더를 팔로워 자세에 수동으로 맞추기 전에는 텔레오퍼레이션을 시작하지 않는다.

**현재 상태 갱신 (2026-10-06):** 위 3도/30 Hz는 10월 5일 당시의 배포 기록이다. 8022의 최신 읽기 전용 `teleoperation-status`는 몸체 15도, Wrist Flex 35도, 그리퍼 20, 최대 상대 목표 0.5도, 20 Hz를 표시한다. 이 완화된 값이 안전하다고 검증된 것은 아니다. 실제 텔레옵 또는 자동 이동 전 현재 시작 자세·작업공간·전원차단 준비를 별도로 확인해야 한다. follower 보정 범위와 기존 데이터 `action`도 일치하지 않으므로 저장 경로를 직접 재생하지 않는다.
