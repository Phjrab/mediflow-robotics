# 7주차 — 촬영 웹 도구와 카메라 설정 구현

기간: 2026-09-14 ~ 2026-09-20

## 목표

Jetson에서 약통 이미지를 안정적으로 촬영하고 라벨과 함께 저장할 수 있는 웹 기반 수집 도구를 구현한다.

## 수행 내용

- Flask 기반 촬영 웹 애플리케이션 구성
- 손목 카메라와 천장 카메라를 논리 이름으로 관리
- 약통, 자세, 파지 전략, 촬영 단계 metadata 저장
- 프레임 저장과 파일명 증가 로직 구현
- 이미지와 annotation JSONL의 일관성 검사 추가
- 잘못된 라벨 값과 누락 필드 검증
- 장치 연결 상태 확인 스크립트 작성
- 저장·검증·API 단위 테스트 작성

## 카메라 초안

- 손목 카메라: `/dev/video6`
- 천장 Astra: 로컬 MJPEG stream
- 천장 RealSense: 로컬 MJPEG stream

## 검증 결과

- 촬영 프로그램의 저장·검증 흐름 동작 확인
- 이후 인수 시점 기준 관련 자동 테스트 11개 통과
- 원본 데이터와 프로그램 코드를 분리해 보존할 구조 마련

## 문제점

- USB 장치 번호가 재연결 시 바뀔 수 있음
- 카메라 프로세스가 동시에 장치를 열면 프리뷰·녹화가 실패할 수 있음
- 연속 촬영만으로는 거의 동일한 프레임이 과도하게 쌓일 수 있음

## 다음 계획

실제 수집된 전체 데이터의 무결성을 검사하고 VLM 베이스라인과 검수 페이지를 구현한다.
