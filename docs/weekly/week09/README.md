## 주간 핵심 결과

| 구분 | 결과 |
|---|---|
| 초기 ACT 학습 | A/B/C 각각 10,000 STEP 정상 완료 |
| 10K 최종 loss | A 0.211, B 0.232, C 0.209 |
| Jetson 배포 | 세 모델 CUDA 로드 및 무결성 확인 |
| 실로봇 ACT-C | 떨림과 접근 실패로 성공 판정하지 않음 |
| 주요 원인 | 시작 자세 분포 이탈, 카메라 입력 오류, 불연속 action chunk |
| A-v2 데이터 | 60 에피소드, 32,597프레임, 3카메라 |
| A-v2 학습 | 100,000 STEP, 최종 loss 0.0514, 약 12시간 |

## 9주차 결론

학습 loss가 충분히 낮아져도 실제 로봇이 성공적으로 움직인다는 보장은 없었다. 카메라 실시간성, 시작 관절 자세, 데이터 배치, action chunk 실행 방식, 안전 제한이 함께 맞아야 한다. 따라서 A-v2 100K 모델도 오프라인 검증과 짧은 감독 시험을 통과하기 전까지 실제 성공 모델로 간주하지 않는다.
