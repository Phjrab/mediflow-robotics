# 9주차 C — 실로봇 시험, 실패 분석, A-v2 개선

## 1. 감독 ACT-C 시험

물리적 전원 차단을 준비한 상태에서 짧은 ACT-C 시험을 수행했다. 소프트웨어상 모델과 카메라가 연결되고 정해진 시간 뒤 초기 위치로 복귀했지만, 실제 로봇은 약통으로 접근하지 못하고 흔들리거나 조금만 움직였다.

관찰 결과:

- 5초 시험: 유효한 접근 없이 떨리다 종료
- 10초 시험: 제한 시간은 정상 종료했지만 유용한 이동이 거의 없음
- 어깨 lift와 elbow 목표가 반복적으로 안전 제한에 걸림
- 손목/그리퍼가 학습 시작 자세와 크게 달랐음

따라서 exit code 0을 작업 성공으로 기록하지 않고 물리적 실패로 판정했다.

## 2. 원인 진단

### 시작 관절 자세 분포 이탈

C 시연 60개의 시작 범위와 실패 시험 자세를 비교했을 때 lift, elbow, wrist flex가 분포 밖이었다. 특히 wrist flex는 학습 중앙값에서 약 13도 이상 벗어났다.

### 카메라 입력 오류

사선 카메라가 실제로 YUYV인데 MJPG로 읽히면서 모델 입력이 녹색 화면이 된 이력이 확인됐다. 모델이 정상 장면 대신 손상된 영상을 받았을 가능성이 있어 카메라 경로를 수정했다.

### ACT action chunk 실행 문제

ACT는 100개 행동을 한 chunk로 예측한다. 현재 장면에서 오프라인 계산한 첫 chunk는 lift 약 73도, elbow 약 91도의 넓은 범위와 최대 약 11도의 연속 변화량을 보였다. 시작 자세가 틀린 상태에서 이 chunk를 소비하면 안전 제한에 계속 걸리며 떨림이 발생할 수 있다.

### 학습 loss와 실제 성공의 차이

1K~10K 체크포인트를 기록된 샘플에서 비교했을 때 10K의 action RMSE가 가장 낮았다. 과거 체크포인트가 덜 흔들리는 것처럼 보여도 작업 자체를 덜 학습했기 때문이므로 체크포인트 교체만으로 해결되지 않았다.

## 3. 적용한 안전·진단 개선

- 로봇별 시작 관절 범위를 검사하는 model-local start gate 추가
- 범위를 벗어나면 정책 명령을 보내기 전에 연결 종료
- 매 시험의 실제 초기 관절값을 로그에 기록
- 한 번의 목표 변화량을 제한하는 안전 clamp 유지
- 정책 행동을 15Hz로 소비하고 30Hz 명령 사이를 보간하는 실행 방식 시험
- 현재 카메라 장면과 학습 시작 장면의 offline first-chunk 비교 도구 구현
- 1K~10K 체크포인트의 기록 데이터 action RMSE 비교 도구 구현
- 화면 가이드를 크기 기준 C/B/A로 수정

## 4. A-v2 재수집과 100K 학습

실패 원인을 학습 STEP 부족 하나로 단정하지 않고, 약통·바구니·카메라·그리퍼 시작 조건을 새로 고정한 A-v2 시연 60회를 수집했다. 수집 전 장치 점유와 모터 6의 일시적 torque status packet 오류도 복구했다.

A-v2는 모든 에피소드에서 세 카메라와 상태·행동 무결성을 검사한 후 100,000 STEP으로 학습했다. 최종 loss는 0.0514였고 5,000 STEP 간격의 체크포인트 20개를 남겼다.

## 다음 단계

1. A-v2 최종 모델과 중간 체크포인트를 기록 데이터에서 비교한다.
2. 현재 세 카메라가 학습과 같은 시점·색상·배치를 제공하는지 확인한다.
3. 시작 관절 자세가 A-v2 분포 안에 있는지 gate로 확인한다.
4. 로봇을 연결하지 않은 offline first-chunk에서 불연속 목표가 없는지 검사한다.
5. 위 조건을 통과한 뒤에만 짧은 감독 시험을 진행한다.
6. 성공/실패를 접근, 파지, 이동, 놓기의 단계별로 기록하고 실패 조건만 추가 수집한다.

## 결론

이번 시험은 실패했지만 카메라, 시작 자세, action chunk, 안전 제한이 실제 성능에 미치는 영향을 구체적으로 확인했다. 다음 실험은 단순히 STEP을 늘리는 방식이 아니라 데이터 분포와 실제 실행 조건을 일치시키는 검증 절차를 먼저 적용해야 한다.
