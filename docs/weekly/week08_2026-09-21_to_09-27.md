기간: 2026-09-21 ~ 2026-09-27

## 1. 기존 데이터 인수와 무결성 검사

- 원본 이미지 1,226장과 JSONL 레코드 1,226개 일치 확인
- archive SHA-256 확인
- 원본을 수정하지 않는 `dataset_v2` 생성
- `before_grasp` 450장을 세션 단위 train/validation/test로 분리
- Qwen3-VL-2B zero-shot과 QLoRA 파일럿 수행
- 로컬 라벨 검수 페이지 구현

초기 모델은 A/upright에 치우쳤고, QLoRA 3 epoch 후에도 약 종류 정확도가 41.18%에서 개선되지 않았다. 코드와 CUDA보다 데이터 검수와 입력 설계가 병목임을 확인했다.

## 3. VLM 재학습과 구조 개선

4개 필드를 한 모델이 모두 예측하도록 학습했으나 B/body 편향이 나타났다. 이후 역할을 다음과 같이 재설계했다.

- 작업 명령: 약 종류 지정
- 코드: 약 종류에서 목표 바구니 결정
- VLM: 자세와 파지 부위 판단

최종적으로 자세 전용과 파지 전용 이중 어댑터를 채택했다.

| 격리 테스트 111장 | 결과 |
|---|---:|
| 자세 정확도 | 84.7% |
| 파지 부위 정확도 | 81.1% |
| 두 값 동시 일치 | 68.5% |
| unknown 재현율 | 68.2% |
| 자동 동작 허가 | 0장 |

- 천장 수직 Astra, 천장 사선 RealSense, 엔드이펙터 카메라 정의

- 프리뷰와 장치 연결 상태 확인

## 주간 결론

VLM의 판단 범위를 실제 이미지에서 확인 가능한 자세와 파지 부위로 제한하자 성능이 개선됐다. 그러나 실동작 수준은 아니므로 모든 결과를 사람 검토 대상으로 유지했다. 3카메라 행동 데이터를 수집할 기반이 준비되어 9주차 ACT 학습으로 전환했다.
