# 5주차 — 데이터 QA와 평가 기준 설계

기간: 2026-08-31 ~ 2026-09-06

> 근거 구분: 초기 설계 문서의 내용을 주차별 개발 단계에 맞춰 재구성했다. 현재 저장소에는 이 기간의 독립적인 파일 타임스탬프가 없다.

## 목표

데이터 누수와 중복을 줄이고, 모델 성능을 단일 정확도가 아닌 항목별로 평가할 수 있게 한다.

## 수행 내용

- blur, 밝기, 파일 손상, JSON 스키마를 자동 점검하는 QA 항목 설계
- perceptual hash 기반 근접 중복 후보 표시
- 같은 촬영 세션이 서로 다른 split에 섞이지 않도록 세션 단위 분할 원칙 정의
- 쉬운 장면과 가림·회전·복수 대상이 포함된 hard test 구분
- 약 종류, 자세, 파지 가능성, 필요 행동, 목표 바구니를 항목별 평가
- 잘못된 바구니 선택률과 `unknown` 재현율을 안전 지표로 추가

## 평가 원칙

- 전체 정확도가 높아도 특정 클래스를 전혀 예측하지 못하면 실패로 판단
- validation은 모델 선택에 사용하고 test는 최종 1회 평가에 사용
- 학습 loss와 실제 로봇 성공률을 분리해 기록
- 실제 작업은 접근, 파지, 이동, 놓기 단계별 성공률로 측정

## 결과

클래스 불균형과 촬영 환경 편향을 수치로 확인할 수 있는 평가 틀을 마련했다.

## 다음 계획

촬영, 검수, 학습, 평가를 각각 독립 실행할 수 있는 프로그램 구조를 정리한다.
