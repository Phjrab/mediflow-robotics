# 1주차 — 프로젝트 주제와 목표 정의

기간: 2026-08-03 ~ 2026-08-09

> 근거 구분: 초기 설계 문서의 내용을 주차별 개발 단계에 맞춰 재구성했다. 현재 저장소에는 이 기간의 독립적인 파일 타임스탬프가 없다.

## 목표

SO-ARM101 로봇팔과 비전 모델을 이용해 약통을 구분하고 지정 바구니로 옮기는 자율 시스템의 최종 시나리오를 정의한다.

## 수행 내용

- 약통 A/B/C와 대응 바구니 A/B/C를 사용하는 분류 작업 정의
- 전체 흐름을 관찰, 대상 판단, 파지 계획, 이동, 배치, 결과 재확인 단계로 구성
- 단순 이미지 분류가 아니라 실제 로봇 행동까지 연결되는 프로젝트 범위 설정
- 잘못된 분류나 불확실한 장면에서는 자동 실행을 중단하고 사람 확인을 요청하도록 원칙 설정
- 카메라, 객체 인식, VLM, 좌표 추정, 로봇 제어가 결합되는 시스템 구조 구상

## 결과

최종 목표를 “약통의 종류와 상태를 판단하고 안전하게 파지한 뒤 올바른 바구니에 넣는 것”으로 정했다. 동시에 인식 결과가 불확실한 경우 행동하지 않는 것을 성공 조건에 포함했다.

## 다음 계획
