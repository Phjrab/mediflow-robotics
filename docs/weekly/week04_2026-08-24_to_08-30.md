# 4주차 — 촬영 조건과 데이터 수집 규칙

기간: 2026-08-24 ~ 2026-08-30

> 근거 구분: 초기 설계 문서의 내용을 주차별 개발 단계에 맞춰 재구성했다. 현재 저장소에는 이 기간의 독립적인 파일 타임스탬프가 없다.

## 목표

같은 장면을 반복 촬영하는 대신 실제 테스트 환경의 변화를 포함하는 데이터 수집 기준을 만든다.

## 수행 내용

- 약통 회전, 위치, 거리, 조명을 의도적으로 변경
- upright/fallen/tilted 상태별 촬영 기준 정의
- A/B/C가 동시에 존재하는 장면과 한 종류만 존재하는 장면 구분
- 가림 정도를 단계별로 나눠 hard case에 포함
- 심한 초점 실패, motion blur, 화면 밖 대상, 의미 없는 연속 중복 제외
- 영상에서 이미지 추출 시 시간 간격과 장면 변화량을 사용해 중복 억제
- 세션·카메라·시각·위치·상태를 metadata에 기록하도록 설계

## 촬영 채택 기준

1. 대상이 식별 가능한 크기로 보여야 한다.
2. 자세와 파지 영역을 판단할 근거가 있어야 한다.
3. 같은 위치·각도의 거의 동일한 프레임은 반복 채택하지 않는다.
4. 실제 추론에 사용할 카메라와 비슷한 시점이 포함돼야 한다.

## 결과

사진 수보다 서로 다른 배치·각도·조명·접근 방향을 가진 독립 세션 수를 우선하는 원칙을 세웠다.

## 다음 계획

데이터 중복 검사, train/validation/test 분리와 성능 평가 기준을 설계한다.
