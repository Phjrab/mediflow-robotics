# 6주차 — 구현 모듈과 개발 순서 정리

기간: 2026-09-07 ~ 2026-09-13

> 근거 구분: 초기 설계 문서의 내용을 주차별 개발 단계에 맞춰 재구성했다. 현재 저장소에는 이 기간의 독립적인 파일 타임스탬프가 없다.

## 목표

설계 내용을 실제 구현 단위로 나누고, 안전한 개발 순서를 확정한다.

## 모듈 구조

- 카메라 연결 및 프레임 상태 확인
- 촬영 세션과 metadata 저장
- 데이터 QA와 split 생성
- 로컬 라벨 검수 UI
- VLM zero-shot/QLoRA 학습 및 평가
- 안전 추론과 명령·바구니 매핑 검사
- LeRobot 행동 데이터 수집
- ACT 정책 학습과 오프라인 검증
- 최종 감독 로봇 시험

## 단계별 우선순위

1. 카메라와 저장 기능 확인
2. 데이터 손상·중복·라벨 검수
3. 로봇과 연결하지 않은 VLM 베이스라인
4. 학습/검증/test 분리와 재학습
5. 3카메라 행동 데이터 수집
6. ACT 오프라인 학습과 체크포인트 확인
7. 카메라·시작 자세·안전 gate 검증
8. 물리적 전원 차단이 준비된 짧은 감독 시험

## 결과

학습이나 로봇 동작부터 시작하지 않고 데이터와 카메라 검증을 선행하는 구현 순서를 확정했다.

## 다음 계획

촬영 웹 도구와 실제 카메라 설정을 구현하고 자동 테스트를 작성한다.
