# 3주차 — 데이터 라벨과 출력 스키마 설계

기간: 2026-08-17 ~ 2026-08-23

> 근거 구분: 초기 설계 문서의 내용을 주차별 개발 단계에 맞춰 재구성했다. 현재 저장소에는 이 기간의 독립적인 파일 타임스탬프가 없다.

## 목표

사람과 모델이 같은 기준으로 약통 상태를 표현할 수 있도록 라벨 체계와 JSON 출력을 정의한다.

## 수행 내용

- 약 종류: `A`, `B`, `C`, `unknown`
- 자세: `upright`, `fallen`, `tilted`, `unknown`
- 파지 가능성: `true`, `false`, `unknown`
- 필요한 행동: `grasp`, `reorient_then_grasp`, `retry_view`, `skip`, `human_check`
- 목표 바구니: `BIN_A`, `BIN_B`, `BIN_C`, `NONE`
- 파지 부위: `lid`, `body`, `unknown`
- 허용되지 않은 키나 설명문이 섞이지 않도록 고정 JSON 스키마 설계

## 판단 기준

- 세워진 약통과 쓰러진 약통의 시각 기준 정의
- 기울어진 상태는 한순간의 프레임만으로 단정하지 않고 불확실하면 `unknown` 사용
- 뚜껑/몸통이 보이지 않거나 접촉 방향이 모호하면 파지 부위를 `unknown` 처리
- 약통 A/B/C와 바구니 A/B/C의 매핑은 코드에서 검증

## 결과

모델이 자신 없는 장면도 강제로 A/B/C 중 하나로 선택하지 않도록 abstention 규칙을 포함한 라벨 체계를 확정했다.
