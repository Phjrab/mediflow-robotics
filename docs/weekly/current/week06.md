# 6주차 — 촬영 웹 도구와 카메라 구성

기간: 2026-09-14~09-20. 기존 인수 기록에서9월18일부터의 구현 시점이 확인되는 작업을 정리했다. 항목별 정확한 날짜가 없는 부분은 인수 시점의 확인 결과다.

## 수행 내용

Flask 촬영 웹 도구를 구성하고 카메라를 논리 이름으로 관리했다. 프레임 저장과 파일명 증가, 약통·자세·파지·단계 metadata 저장, 이미지와 annotation JSONL의 일관성 검사 기능을 구현했다.

라벨 누락과 허용되지 않은 값을 검증하고 장치 상태 확인 스크립트 및 저장·검증·API 테스트를 작성했다. 인수 기록 기준 관련 자동 테스트11개 통과가 확인된다. 이것을 모두 이 주의 같은 날짜에 실행했다고 해석하지 않는다.

## 문제·다음 계획

USB 재연결에 따른 장치 번호 변경과 여러 프로세스의 카메라 점유 충돌 가능성을 확인했다. 원본 데이터는 별도로 보존하고, 다음 주에는 전체 무결성 검사와 VLM 베이스라인·라벨 검수를 진행한다.
