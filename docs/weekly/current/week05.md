# 5주차 — 구현 모듈과 개발 순서

기간: 2026-09-07~09-13. **초기 설계 재구성; 실제 수행일의 독립 근거 없음.**

## 설계 내용

카메라 연결, 세션 저장, QA·분할, 라벨 검수, VLM 학습·평가, 행동 시연 녹화, ACT 학습, 실로봇 검증을 독립 모듈로 나눴다. 먼저 관측·저장·데이터 무결성을 확인하고 모델 학습과 물리적 실행으로 넘어가는 순서를 정했다.

모델과 UI가 살아 있는 것만으로 카메라 실시간성이나 작업 성공을 인정하지 않는다. 학습 데이터와 현재 입력 시점·색상·시작 관절 자세가 맞는지 별도로 확인한다. 감독 시험과 즉시 전원 차단 준비를 실제 동작 전 조건으로 둔다.

## 산출물·다음 단계

프로그램 구성 및 단계별 개발 계획. 이후 날짜가 확인되는 촬영 웹 도구 구현으로 연결된다. 이 기간에 실제 코드나 로봇 시험이 완료됐다고 단정하지 않는다.
