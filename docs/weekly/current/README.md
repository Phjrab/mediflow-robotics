## 기록 신뢰도와 작성 원칙

1~5주차에는 해당 날짜의 독립적인 활동일지가 없다. 기획 문서를 보고서의 개발 단계에 맞춰 정리한 것으로, 그 주에 실제로 전부 수행했다고 인증하지 않는다. 학교 제출 시 실제 활동일지가 있으면 보완해야 한다. 현재 인수 기록에서 구현 시점이 확인되는 작업은9월18일부터다.

학습 완료, 코드 적용, 로봇 없는 테스트 통과, 실제 접근 성공, 바구니 투입 성공은 서로 다른 결과다. 확인되지 않은 성공률·고장 원인·실행 결과는 만들지 않는다. 낮은 학습 loss와 프로세스 exit0은 작업 성공의 증거가 아니다.

## 최신 결론

A 작업의 접근과 파지 관찰은 있었지만 안정적인 바구니 투입은 아직 확인되지 않았다. A-v3 trim05 100K 모델을 등록했고, 행동 순서와 관절 추종의 어긋남 및 종료 시 토크 해제 문제를 진단했다. 텔레옵은 시작 오프셋을 없애고 리더 절대 자세를 따르는 방식으로 수정·배포했다. 새 종료 유지 및 텔레옵 정렬 방식은 로봇 없는 테스트를 통과했지만 실제 검증은 남아 있다.

이 보고서에는 비밀번호·인증 토큰·원본 촬영 영상·모델 가중치를 포함하지 않는다. 구체적인 장치 주소 대신 논리 이름으로 기록한다.
