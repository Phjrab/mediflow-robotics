# 4주차 — 데이터 품질과 평가 기준

기간: 2026-08-31~09-06. **초기 설계 재구성; 실제 수행일의 독립 근거 없음.**

## 설계 내용

이미지 손상·흐림·밝기·JSON 필드·근접 중복을 검사하는 QA 항목을 정리했다. 같은 촬영 세션이 train/validation/test에 동시에 들어가지 않도록 세션 단위 분할을 계획했다.

평가는 약 종류·자세·파지 부위별로 분리하며 클래스 편향, 잘못된 바구니 선택, unknown 처리도 확인한다. 학습 loss, 오프라인 정확도, 실로봇 성공률은 서로 다른 지표로 기록한다. 실제 작업은 접근·파지·이동·놓기 단계별로 판단한다.

## 산출물·다음 단계

데이터 QA와 모델 선택 기준 초안. test를 보고 반복적으로 모델을 고르는 누수를 피하고 validation으로 후보를 선택하는 원칙을 정했다. 다음 단계는 촬영·검수·학습·평가 모듈의 구현 순서 확정이다.
