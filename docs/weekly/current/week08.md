## 실로봇 평가와 재학습

ACT-C 시험은 떨림과 접근 실패로 성공 판정하지 않았다. 시작 자세와 데이터 분포, 카메라 입력, action chunk와 명령 제한을 비교했다. A=큰 약통, B=중간, C=작은 약통으로 사용자 정의를 바로잡았다.

A-v2는 고정된 새 조건으로60회/32,597프레임을 수집하고100,000 STEP으로 학습했다.10월3일06:25 KST 완료 기록, 최종 loss0.0514015, 소요12시간00분47초.5,000 STEP마다 체크포인트20개를 보관했다.
