# 2주차 — 라벨과 출력 스키마

기간: 2026-08-17~08-23. **초기 설계 재구성; 실제 수행일의 독립 근거 없음.**

## 설계 내용

약 종류 A/B/C/unknown, 자세 upright/fallen/tilted/unknown, 파지 부위 lid/body/unknown을 구분하는 라벨 체계를 정리했다. 필요한 행동과 목표 바구니를 구조화된 JSON으로 표현하고 허용되지 않은 값과 필드를 검증하도록 설계했다.

단일 프레임만으로 기울어짐이나 접촉을 확신하지 않으며, 가림·화면 밖 대상·모호한 파지는 unknown으로 남기는 원칙을 정했다. unknown은 오류를 숨기기 위한 라벨이 아니라 판단 근거 부족의 표현이다.

## 산출물·다음 단계

라벨 정의 및 출력 스키마 초안. 이후 실제 데이터 검수에서 뚜껑/몸통 구분을 추가하고 성능을 평가한다. 약 종류와 바구니 매핑은 모델 판단과 별개로 코드에서 확인한다. 이 주차는 기획 정리이며 구현·학습 완료의 증거가 아니다.
