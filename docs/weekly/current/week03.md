# 3주차 — 촬영 조건과 수집 규칙

기간: 2026-08-24~08-30. **초기 설계 재구성; 실제 수행일의 독립 근거 없음.**

## 설계 내용

약통 위치·회전·거리·조명·가림을 변화시키고, 세워진 상태와 쓰러진 상태, 뚜껑과 몸통 파지를 구분해 수집하도록 계획했다. 실험 시 여러 약통이 놓인다면 수집에도 방해 대상을 포함하는 원칙을 세웠다.

사진 장수보다 서로 다른 시연·세션의 다양성을 우선했다. 영상에서 프레임을 추출할 때는 거의 같은 장면이 과도하게 중복되지 않도록 간격과 변화량을 고려한다. 세션·시점·촬영 단계 metadata를 남겨 이후 누수 검사를 가능하게 한다.

## 산출물·다음 단계

촬영 채택/제외 기준과 데이터 수집 계획. 흐림·화면 밖 대상·잘못된 라벨·의미 없는 중복은 검수 대상으로 분리한다. 다음 단계는 품질 점검과 세션 단위 데이터 분할 설계다.
