# 9주차 B — 대기 구간 축소·기존 데이터 재학습

## 원본 보존과 두 실험

초기 대기 구간이 접근 행동을 지연시키는 가설을 시험하기 위해 기존 A-v2에서 두 파생 데이터셋을 만들었다. 원본60회/32,597프레임은 수정하지 않았다.

| 실험 | 회수 | 프레임 | 처리 |
| --- | ---: | ---: | --- |
| trim05 | 60 | 27,564 | 지속적인 몸통 행동 시작0.5초 전부터 유지; 선행 대기5,033프레임 제외 |
| 48회 대조 | 48 | 24,588 | 행동 시작이 늦은12회를 별도 실험에서 제외 |

12회 제외는 그 시연이 잘못됐다는 판정이 아니라 가설을 비교하는 실험이다. 영상은 재인코딩 없이 복사하고 로더의 시작 offset·인덱스·행동/상태 통계를 다시 구성했다. 두 데이터셋 모두 수치 행 전체, 영상7개 해시, 표본72장 source 대조 검증을 통과했다. 이미지 통계는 원본에서 가져와 파생 데이터에 대해 근사라는 한계가 있다.

## 학습·등록

trim05는10월6일23:04 KST 시작 기록이 있고100,000 STEP 최종 모델을10월7일 확인했다. Jetson에서 기존 A-v2를 덮어쓰지 않고 `ACT-A V3 trim05 medicine A to basket A 3cam 100k`로 등록했다.

48회 모델은 앞선 학습의 성공 종료와 최종 체크포인트 존재를 확인한 뒤 시작하도록 순차 실행을 구성했다. 이 보고서는48회 모델의 최신 진행률·완료를 확인하지 않았으므로 완료 모델로 기재하지 않는다. 본 보고서 작성 중 새로운 학습을 시작하지 않았다.

학습 지표는 W&B와 로컬 체크포인트로 분리 관리한다. 브라우저 로그인/링크 오류는 모델 파일 존재와 별도로 확인한다. 새 학습 loss나 성공률을 추정해 적지 않는다.

근거:10월6일 trim05/48회 파생 데이터 검증·상태 기록,10월7일 모델 등록 및 시험 보고서. 최대STEP은 완료 조건이지 실제 작업 성공 조건이 아니다.
