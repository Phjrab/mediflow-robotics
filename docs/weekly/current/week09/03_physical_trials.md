# 9주차 C — 접근·파지 이후 바구니 실패 진단

## 10월7일 실험

| 시험 | 실제 관찰/기록 | 판단 |
| --- | --- | --- |
| 초기3초 | 사용자는 A 쪽 접근 및 이상 없음을 보고 | 접근 진단 통과, 투입 성공 아님 |
| 60초 시험 | 약8초 파지,10초 기울어짐,12~14초 바구니 접촉·이동, A가 바구니 밖에 남음 | 픽앤플레이스 실패 |
| 몸통 도달 허용오차3도 | 약2.70초에 첫 목표 시간초과 | 목표 유지/중단 확인, 접근 미완료 |
| 팔꿈치 허용오차4도 | 약11.25초 접근 뒤 시간초과; 이후 팔 낙하·책상 접촉 보고 | 실패, 추가 동작 중단 |

60초 시험에서는 관절 표본1,730개와 두 카메라60장을 저장했다. 그리퍼 재개방 명령이 진행된 시점에 팔꿈치는 모델의 의도 목표보다 약21.1도 뒤에 있었다. 실제 모터에 전송한 명령은5도 제한 후 값이므로, 의도 목표와 실측 차이를 곧바로 서보 고장으로 해석하지 않는다.

성공 시연 표본에는 바구니 투입까지 포함되어 있다. 따라서 단순히 투입 영상이 없어서 못 했다고 설명할 수 없다. 정책의 파지·이동·놓기 순서가 실제 관절 이동보다 앞서가는 실행 계층의 어긋남을 주요 조사 대상으로 삼았다. 장면/시작 자세 및 모델 일반화도 별도 가능성으로 남아 있다.

4도 시험의 중단 오차는4.014898도였고2.006초 대기 후 종료했다.60초 설정이10초로 줄어든 것이 아니다. 사용자 보고상 집게가 열린 상태로 팔이 책상에 닿았고 파손은 없어 보였지만, 무손상으로 인증하지 않았다.

## 결론

접근과 파지 개선은 관찰되었으나 안정적인 투입은 미달성이다. 떨림을 정상으로 간주하지 않는다. 더 많은 학습이나 더 긴 실행시간이 제어·종료 문제를 해결한다고 단정하지 않는다. 근거: 저장 관절/카메라 추적, 각 시험 결과 보고서, 사용자의 현장 관찰.
