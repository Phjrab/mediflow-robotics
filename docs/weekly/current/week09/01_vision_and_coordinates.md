# 9주차 A — ArUco·OpenClaw·작업공간

## 10월5~6일 수행

기존 ArUco·Depth·URDF·카메라 자산을 조사하고 원본을 보존했다. 작업대 마커0~3, 바구니 A=6/B=5/C=4 매핑을 확인했다. X 표시는 다른 작업의 흔적이라는 사용자 확인에 따라 픽업 기준에서 제외했다.

원본 천장 프레임에서 약통 뚜껑 중심과 바구니 좌표를 추출하고 작업대 XY로 변환했다. C/B/A 고정 배치 순서로 약통 신원을 대응하는 것은 임의 배치에서 약통을 분류하는 기능과 다르다.

OpenClaw용 읽기 전용 장면 검사·dry-run 계획 초안을 만들었다. 이 초안은 OpenClaw를 통한 실제 자동 작업 연결 완료가 아니다. TCP·작업대↔로봇 변환·작업영역·IK가 검증되지 않은 경우 경로 실행을 차단했다. RGB-D 진단의 약21.1mm RMS는 정밀 파지 좌표로 승인하지 않았다.

텔레옵 관절 스트림으로 두 차례 움직인 범위를 기록했다. 관찰된 최소/최대값은 도달 이력이지, 그 사이 모든 관절 조합과 장애물 배치가 안전하다는 증명이 아니다. 테이블 접촉 관찰도 있어 전체 영역을 안전거리로 인증하지 않았다.

## 산출물·남은 일

장면 검사기, 좌표/그리퍼 기준점 진단, 실행 차단 계획기, 작업공간 수집 도구. 기존 오프라인 TCP 검토 기록에서30개 회귀 테스트 통과가 확인된다. 실제 TCP와 독립 작업대 기준점, 높이·충돌 여유·정지 경로는 별도 실측과 검증이 필요하다.

근거:10월5일 OpenClaw/ArUco 진행 기록,10월6일 오프라인 TCP 검토 및 작업공간 측정 기록. ACT 추론과 이 읽기 전용 OpenClaw 경로는 별도 실행 경로다.
