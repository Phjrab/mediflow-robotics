# 9주차 E — 현재 상태와 다음 검증

기준: 2026-10-07. 미완료 항목을 완료로 쓰거나 임의의 전체 달성률을 제시하지 않는다.

## 완료한 작업

- 원본 촬영 데이터 보존 및 파생 데이터 무결성 검증.
- VLM 이중 어댑터 오프라인 평가와 A/B/C ACT 초기 학습.
- A-v2와 trim05 A-v3의100K 모델 확인 및 등록.
- 세 카메라 연결·실시간성 및 장치 점유 문제 진단.
- 기존 시연의 투입 단계 확인, 실험 관절/이미지 추적 도구 구현.
- 몸통 추종 기반 행동 순서 보정, 종료 토크 처리, 절대 텔레옵 시작 정렬 코드 적용과 비동작 테스트.

## 남아 있는 작업

- 책상 접촉 뒤 집게·관절의 휨/걸림 및 작은 텔레옵 움직임 확인.
- 새 정렬/종료 유지의 감독하 실제 검증.
- 약한 떨림과 지속 관절 오차의 근본 원인 분리.
- 바구니 투입까지 한 번의 전체 작업과 반복 성공률 확인.
-48회 대조 모델의 최신 학습 상태와 기존 모델 대비 평가.
- OpenClaw 경로의 실제 TCP·좌표변환·작업영역·IK·정지 검증 및 실행 연동.

## 다음 실험 순서

1. 사용자 현장 점검 후, 리더를 정지해 둔 상태에서 시작 정렬과 작은 텔레옵 추종을 확인한다.
2. 실제 팔로워 관절값·카메라·약통·바구니를 학습 시작 조건과 비교한다. 숫자가 맞는 것만으로 기계 안전을 인증하지 않는다.
3. 제한과 제어 설정을 기록한 짧은 감독 시험에서 접근·파지·상승·이동·놓기의 단계별 결과를 확인한다.
4. 추종이 늦을 때 그리퍼가 먼저 열리는지, 명령이 맞는데 관절이 못 가는지, 모델 목표 자체가 틀리는지 분리한다.
5. 제어·관측 문제를 먼저 정리한 뒤 기존 trim05와48회 대조 모델을 비교하고, 필요한 조건만 추가 수집한다.

이번 보고서 작성 자체로 학습·추론·로봇 동작을 새로 실행하지 않았다. 보고서 공개는 소프트웨어/실험 기록 공유이며 로봇 안전이나 의료 적용 인증이 아니다.
