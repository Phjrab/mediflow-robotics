# 7주차 — 데이터 검수·VLM 학습·3카메라 기반

기간: 2026-09-21~09-27.

## 수행 내용

원본 이미지1,226장과 레코드1,226개의 무결성을 확인하고 원본을 수정하지 않는 파생 데이터셋을 구성했다. 세션 단위 분할, zero-shot 비교, QLoRA 파일럿, 한글 라벨 검수 페이지를 구현했다. 파지 부위 lid/body/unknown 검수와 추가 영상 수집도 진행했다.

9월23일 신규494장을 반영한 검수와 중복 제외 작업을 거쳐 독립 장면 데이터셋을 구성했다. 초기 모델의 클래스 편향을 확인한 뒤, 약 종류는 작업 명령으로 지정하고 목표 바구니는 코드로 매핑하며 VLM은 자세·파지 부위를 판단하도록 역할을 줄였다.

9월26일 최종 이중 어댑터의 격리 테스트111장 결과:

| 지표 | 결과 |
| --- | ---: |
| 자세 정확도 | 84.7% |
| 파지 부위 정확도 | 81.1% |
| 두 항목 동시 일치 | 68.5% |
| 자동 로봇 동작 허가 | 0장 |

천장 수직 Astra, 천장 사선, 엔드이펙터 카메라를 LeLab 행동 데이터 입력으로 구성하고 Astra V4L2 bridge를 준비했다.

## 결론·근거

VLM 오프라인 성능은 개선됐지만 실동작을 승인할 수준으로 평가하지 않았다. 이후 ACT 시연 학습으로 전환한다. 근거:9월23·25·26일 VLM 보고서 및9월27일 카메라 구성 보고서. VLM과 ACT는 별개이며 이 결과가 로봇 제어 성공률을 의미하지 않는다.
