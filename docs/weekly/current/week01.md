# 1주차 — 목표와 시스템 역할 정의

기간: 2026-08-10~08-16. **초기 설계 재구성; 실제 수행일의 독립 근거 없음.**

## 목표·설계 내용

SO-ARM101 로봇팔로 약통 A/B/C를 지정 바구니에 옮기는 시나리오를 정의했다. 전체 단계를 관찰→대상 판단→파지→이동→투입→결과 확인으로 분리했다. 카메라는 관측, 비전 모델은 판단, 좌표 추정과 제어 코드는 이동 계획을 맡도록 역할을 나눴다.

불확실한 장면에서는 사람 확인을 요청하고, 비전 모델의 문장을 그대로 모터 명령으로 사용하지 않는 원칙을 세웠다. 기존 데이터·카메라·캘리브레이션을 임의로 초기화하지 않는 보존 원칙도 포함했다.

## 산출물·다음 단계

최종 작업 목표와 모듈 책임을 정의한 설계 초안. 다음 단계는 데이터 라벨과 모델 출력 형식의 구체화다. 근거는 프로젝트 개발 프롬프트와 이전 기획 정리이며, 이 기간의 구현 완료나 실로봇 성공을 주장하지 않는다.
