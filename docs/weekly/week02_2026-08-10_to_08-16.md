# 2주차 — 시스템 역할 분리와 안전 원칙

기간: 2026-08-10 ~ 2026-08-16

> 근거 구분: 초기 설계 문서의 내용을 주차별 개발 단계에 맞춰 재구성했다. 현재 저장소에는 이 기간의 독립적인 파일 타임스탬프가 없다.

## 목표

카메라부터 로봇 실행까지의 책임을 한 모델에 몰아넣지 않고 모듈별로 분리한다.

## 수행 내용

- Camera: 천장과 손목 시점의 실시간 RGB 영상 제공
- Object detector: 약통과 바구니 후보 영역 탐지
- ArUco/좌표 추정: 작업대와 목표 위치 기준 좌표 제공
- VLM: 약통 상태, 파지 가능 여부와 필요한 행동 판단
- Robot planner: 검증된 목표와 좌표로 경로 생성
- Safety gate: 불확실성, 잘못된 매핑, 장치 오류 시 실행 차단

## 핵심 안전 원칙

1. VLM이 직접 모터 명령을 생성하지 않는다.
2. 약 종류와 목표 바구니 매핑이 어긋나면 실행하지 않는다.
3. `unknown`, 심한 가림, 화면 밖 대상은 사람 확인 대상으로 보낸다.
4. 실제 동작 뒤에는 새 영상을 받아 결과를 재확인한다.
5. calibration, 카메라 장치, 원본 데이터를 임의로 초기화하지 않는다.

## 결과

학습 모델은 판단을 보조하고, 좌표 계산과 안전 제약은 명시적인 코드가 담당하는 구조를 정했다.

## 다음 계획

학습 데이터의 클래스, 자세, 파지 상태와 출력 형식을 구체화한다.
