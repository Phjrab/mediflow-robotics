# 공개 소스·실험 기록 보관 정책

2026-10-07 사용자 요청으로 기존 공개 저장소에 코드와 실험 결과를 추가하도록 준비한다. 실제 공개 완료 여부는 커밋과 Releases 파일 목록으로 확인한다. 현장 원본은 수정하지 않고 별도 공개 사본만 만든다.

## 포함

- 촬영 웹 도구와 저장·검증 코드 및 테스트.
- VLM 검수 UI, 데이터 준비, 학습·평가·안전 추론 코드와 설정.
- ACT 데이터 파생/검증, 학습·W&B·배포 보조 코드와 Jetson 패치 및 테스트.
- ArUco·좌표 검토·OpenClaw 읽기 전용/dry-run 도구와 구성.
- 데이터 분할·라벨 metadata와 평가 요약. 원본 이미지가 없어 저장소만으로 학습 입력을 완전히 복원할 수는 없다.
- 주차별 보고서, 실험 결과, 학습 곡선과 관절 명령 수치 그래프.

## 제외

Git 소스 이력에서 비밀번호·인증 토큰·환경 비밀 파일, 가상환경·모델 캐시·가중치,86MB 원본 압축파일, 원본/현장 카메라 이미지·영상, 실제 장치 실행 로그와 관절 스트림, 임시 파일·백업·캐시는 제외한다. 사용자 추가 요청에 따라 원본 촬영 자료와 학습 모델은 GitHub Releases 자산으로 별도 준비한다. 인증정보와 가상환경, 전체 optimizer 상태는 Releases에도 포함하지 않는다. 현장 원본은 보존한다.

공개 사본에서 사설 장치 IP는127.0.0.1로, 개인 홈 경로는`/home/USER`로 치환했다. SSH 사용자명도 예시로 바꿨다. 복제 후 현장 장치 주소와 프로젝트 경로를 직접 설정해야 하며 예시값으로 실제 장치에 접속할 수 있다고 가정하지 않는다. 원본 코드·데이터·캘리브레이션은 변경하지 않았다. 문서의 현장 이미지 참조는 공개판에서 로컬 보관 설명으로 대체한다.

## 재현과 상태 구분

저장소 다운로드·설치만으로 로봇을 켜거나 자동 실행하지 않는다. 테스트는 가짜 장치/비동작 테스트부터 수행한다. 하드웨어 학습·추론·텔레옵 명령은 별도 현장 점검과 승인이 필요하다. 현장 서비스 파일과 실행 스크립트는 참고 자료이지 자동 설치 권한이 아니다.

`outputs/`의 과거 날짜 보고서는 해당 실험 시점 기록이다. 현재 상태는 최신 주차별 목차와 최신 제어/텔레옵 결과를 먼저 확인한다. 학습 완료·오프라인 평가·실제 투입 성공을 구분하며, 안정적인 바구니 투입과 새 종료 유지/정렬의 실제 검증은 아직 완료로 주장하지 않는다.

패치에 포함된 외부 프로젝트 소스의 원래 저작권·라이선스 헤더를 보존한다. 프로젝트 전체의 별도 배포 라이선스를 임의로 새로 부여하지 않는다.
