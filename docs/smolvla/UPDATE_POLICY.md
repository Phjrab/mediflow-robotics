# 앞으로의 진행 기록 갱신 규칙

2026-11-04 사용자 요청: 이 프로젝트의 문제·원인·해결·현재 진행을 이 저장소에 올리고 앞으로도 계속 남긴다. 이 요청은 문서 업로드 권한이며 로봇 구동·학습·설치·모델 및 원본 업로드의 포괄 승인이 아니다.

## 갱신 시점

이 프로젝트에서 작업 결과나 새 실패·정정·의사결정이 생길 때 CURRENT_STATUS.md와 WORK_LOG.md를 갱신하고, 일반 커밋으로 이 저장소에 반영한다. 사용자에게 같은 문서 업로드 허락을 매번 다시 묻지 않는다. 사용자가 해당 작업에서 읽기 전용·파일 수정 금지·push 금지를 명시하면 그 지시를 우선한다. 그 경우 미반영으로 보고하고 다음 허용된 갱신에 포함한다.

이 규칙은 작업을 수행하는 채팅·에이전트를 위한 것이다. 채팅 밖에서 상시 감시하거나 사용자 PC에 접속하는 자동화를 설정한 것은 아니다.

## 매번 적을 내용

1. 날짜와 이번 목적·변경된 방향.
2. 문제 증상과 확정 원인. 확정하지 못한 가설은 UNVERIFIED.
3. 수정·복구 내용과 되돌린 시도. 실패한 시도도 삭제하지 않음.
4. 파일·설정·버전·검사 범위와 결과. 개별 테스트·전체 회귀·실제 장치 결과를 구분.
5. 누가 어디서 실행했는지: 로컬 파일 검사, 사용자 Jetson 실행 보고, 다른 학습 PC 기록, 운영자 확인을 구분.
6. 현재 완료·진행·차단·NOT_RUN과 다음 실행 조건.
7. 공개 커밋 SHA와 링크. 업로드 실패 시 NOT_PUSHED와 원인을 남김.

## 보존과 공개 범위

- 과거 보고서의 날짜별 의미를 보존하고 새 정정 항목을 추가한다. 현재 상태에는 최신 결론을 명시한다.
- 인증정보·토큰·비밀번호·개인키·셸 기록 원문·실제 장치 접속 주소·개인 홈 절대 경로를 공개하지 않는다.
- 원본 이미지·영상·모델·가상환경·원문 장치 스트림·보정 원본은 진행 문서 커밋에 싣지 않는다. 필요한 별도 자료 전달은 범위와 대상을 따로 확인한다.
- 테스트 PASS·코드 작성·모델 학습·로딩·모터 송신·물리 투입 성공을 동일하게 표현하지 않는다.
- 이번 단독 SO101Follower 첫 동작 시험을 RobotController 단일 경로 G5나 MVP G6 통과로 쓰지 않는다.
- 원격 최신 HEAD와 변경 파일을 확인하고 일반 fast-forward 갱신만 한다. 다른 사람의 변경을 덮거나 force push하지 않는다.

- TRAINING_SUMMARY_20261104.md: 이번 137회 학습 범위. 추가 학습은 다른 실험으로 기록.
