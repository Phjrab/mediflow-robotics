이번 갱신은 공개 진행 문서다. 실제 실행 스크립트 최신 사본, 보정 원본, home JSON, 원본 영상/데이터, 모델 가중치, 인증정보, 원문 장치 로그를 함께 업로드한 것이 아니다. 기존 학습 인계 자료는 `codex/smolvla-handoff-20261102` 브랜치에 있으며, 그 브랜치의 오래된 회차/NOT_RUN 표기보다 이 날짜별 상태 요약을 우선해서 읽는다. 브랜치를 받는 것만으로 실제137회 데이터/모델/실행 환경이 복원되지는 않는다.

이 문서의 사용자 보고와 운영자 확인은 원격 하드웨어를 다시 검사한 결과가 아니다. [기록 규칙](UPDATE_POLICY.md)에 따라 작성·모의 검사·실행·물리 성공을 구분한다.
