## 2026-11-19 — 원래 FIFO 재현, 지연 실측, 독립 검증

- MF-03은 원본 10회 SmolVLA와 실시간 모의 관절 및 저장 RGB 3장으로 READY 후 180.000089초를 실행했다. 순서대로 소비한 2,897개 액션 중 누락 0개, 총 대기 83.656초, 16.0944 actions/s였다. 총괄이 원본 trace를 회수해 액션 2,897개, 후속 요청 57회, 다음 모의 목표 피드백 2,896개를 행별 검산했다.
- 저장 관측 1개와 같은 seed에서 RGB 포장 후보를 AB/BA로 비교했다(예열 제외 8쌍). 입력 포장 등 부모 측 잔여 시간의 중앙값은 11.95→8.79 ms이나 전체 호출 p50은 1.417→1.421초, p95는 1.431→1.445초였다. 50×6 출력 해시는 같았고 후보를 운영에 채택하지 않았다.
- 저장 시점 3개 × seed 2개에서 denoising 10·4·1회를 짝지어 비교했다. p50/p95는 10회 1.379/1.406초, 4회 0.791/0.816초, 1회 0.504/0.518초였다. 1회에서 기본 대비 팔꿈치 최대 차이는 41.26°, 어깨 올림은 30.75°였다. 표본의 인접 점프 검사는 통과했지만 보호 전 절대 목표에서 범위 이탈이 있었다. 4회·1회로 측정한 180초 처리율은 없으며 운영 기본 10회를 유지한다.
- MF-05가 6축 출력 순서 검사의 결함을 재현했다. 수정한 X-VLA 오프라인 로더는 학습 메타데이터·processor·기준 출력을 교차 검사한다. 합성 및 공식 CPU 후처리 경로 25개를 총괄 통합본에서 재실행해 통과했다. 실제 X-VLA 6축 체크포인트 실행은 남아 있다.
- MF-01은 원본 Parquet 6개·영상 24개와 선택 구간 411개를 대조하고 137회·63,551행을 학습 전용으로 고정했다. 파생본의 공식 CPU 로더로 50액션 경계와 색상별 실제 입력을 검증했다. 당시 병합본과의 바이트 동일성과 독립 시험 성적은 미검증이다.
- Windows 기준 코드 회귀는 212개 중 210개 통과, POSIX 전용 2개 건너뜀. MF-03 검증 코드의 Jetson CPU 모의 회귀는 기존 런처의 라이브러리 경로를 적용한 뒤 218/218 통과했다. 첫 임시 실행의 torch import 오류 2개는 동일 사본에서 재검사했다. 모터 통신의 현장 복구와 실제 집기·지정 바구니 투입은 보류다.
