## 현장 사이트 — 인터넷 공개 배포 아님

| 기능 | 주소 | 이번 확인 결과 |
| --- | --- | --- |
| LeLab 메인 | http://192.168.50.20:8022/ | Jetson 내부에서 HTTP200 |
| 텔레옵 | http://192.168.50.20:8022/teleoperation | 동일 LeLab 서비스 경로; 동작은 별도 승인/현장 점검 필요 |
| 카메라 설정 | http://192.168.50.20:8022/calibration | 동일 LeLab 서비스 경로 |
| 시연 녹화 | http://192.168.50.20:8022/recording | 동일 LeLab 서비스 경로 |
| 학습 화면 | http://192.168.50.20:8022/training | 동일 LeLab 서비스 경로 |
| 모델 추론 | http://192.168.50.20:8022/inference | 동일 LeLab 서비스 경로; 열람이 실행 승인은 아님 |
| 별도 영상 촬영 도구 | http://192.168.50.20:8011/ | 이번 확인에서 응답 없음; 현재 꺼져 있음 |
| 로컬 라벨 검수 | http://127.0.0.1:8020/ | PC 내부 확인에서 응답 없음; 현재 꺼져 있음 |

`192.168.50.20`은 사설 LAN 주소로, 같은 네트워크이거나 기존 승인된 VPN 연결이 있어야 접속한다. `127.0.0.1`은 실행 중인 컴퓨터 자신이며 다른 PC에서 열면 그 PC를 가리킨다. 서버가 꺼져 있으면 주소가 맞아도 열리지 않는다. 이 문서 작성 과정에서 촬영·검수·추론 서비스를 새로 켜거나 로봇을 움직이지 않았다.

촬영 소스의 기본 포트는8020이지만 실제 현장의 별도 영상 촬영 서비스는 과거8011로 운영했다. 코드를 내려받은 다른 환경에서는 실행 포트/주소를 직접 확인해야 한다.8000 구형 LeLab을 현재8022와 동시에 켜면 카메라 점유 충돌이 생길 수 있어 대체 주소로 안내하지 않는다.
