# LeLab 녹화 쓰기 제한

설치된 LeLab 및 SDK의 지정 파일 해시가 일치할 때 `prepare_overlay.py`가 녹화 모듈 사본을 만든다. `mode.py guarded`는 유휴 웹 서비스의 녹화 경로에 사본을 적용한다. `mode.py original`은 해당 서비스 옵션을 해제한다. 원본 모드는 기존 녹화 시작 시 보정·모터 설정을 쓸 수 있다.

녹화 중에는 리더 토크 해제, 팔로워 토크 설정·목표 위치, 그리퍼 ID 6의 토크 한계만 허용한다. 통신 경계에서 ID·주소·바이트 폭·값·체크섬을 확인한다. 그 밖의 명령은 송신 전에 중단하고 서비스 로그에 기록한다. 정상 종료와 예외 처리 모두 각 축에 토크 해제를 요청한 뒤 토크 레지스터를 읽는다. 종료 보고서는 사용자 상태 디렉터리의 `lelab-record-guard` 아래에 저장한다.

## Jetson 모의 녹화 시험

장치 설정은 배포 폴더의 비공개 `site.local.json`에서 읽는다. `ports.leader`와 `ports.follower`는 각각 해당 하드웨어의 고정 시리얼 경로이며 `trial_dataset`은 입회 시험 전용 이름이다.

2026-11-25. 설치된 LeLab의 녹화 함수와 LeRobot 녹화 루프를 실행했다. SDK 패킷은 메모리 포트가 수신했고 실제 시리얼 열기는 예외 처리했다. 카메라 영상과 데이터셋 파일 저장은 모의 대상이다. 허용·차단 건수의 단위는 패킷이다. 모든 행에서 모의 리더·팔로워의 토크 레지스터는 각각 6축 모두 0이었다.

| 경로 | 허용 송신 | 금지 차단 | 금지 송신 | 회차 저장 호출 |
|---|---:|---:|---:|---:|
| 정상 종료 | 27 | 0 | 0 | 1 |
| SIGINT | 27 | 0 | 0 | 0 |
| 웹 중단 플래그 | 27 | 0 | 0 | 0 |
| 목표 송신 직전 중단 | 27 | 0 | 0 | 0 |

| 카메라 초기화 실패 | 12 | 0 | 0 | 0 |
| 팔로워 토크 활성화 중 실패 | 20 | 0 | 0 | 0 |

## 실물 입회 확인

Jetson 터미널에서 설치 폴더의 `python3 record_trial.py`를 실행한다. 첫 회차는 투입 후 Enter로 저장한다. 두 번째는 녹화 중 Ctrl+C를 눌러 중단한다. 두 번 모두 출력된 세션 보고서에서 리더·팔로워 토크 6축이 각각 0인지, 오류와 차단 건수가 있는지 확인한다. 시험은 전용 데이터셋 이름을 사용한다. 실물 결과는 두 경로 모두 미확인이다.
