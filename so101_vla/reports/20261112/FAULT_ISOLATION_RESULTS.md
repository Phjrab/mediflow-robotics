# 6축 온도 응답 급변 비교 결과

2026-11-12. 실제 모터 레지스터 쓰기 0회, live NOT_RUN. 모든 실제 검사는 토크 OFF를 읽어 확인한 뒤 READ 명령만 전송했다. 높은 온도 응답을 무시하는 수정, 보호 기준 변경, 펌웨어 변경은 하지 않았다.

## 확인된 결과

| 비교 조건 | 같은 방식으로 읽은 결과 | 해석 |
|---|---|---|
| 기존 팔로워 보드·기존 출력·원래 6축 | 손목 28→38→28°C, 그리퍼 31→41/44→31°C | 원래 구성에서 급변 재현 |
| 같은 보드의 옆 빈 흰색 3핀 출력 | 그리퍼 32→44→32°C, 32→46→32°C, 분리 읽기 최고 50°C | 특정 출력 소켓 하나만의 문제로 설명하기 어려움 |
| 기존 리더 보드로 교체, 팔로워 USB 선/포트 유지 | 손목 28→38/37→28°C, 그리퍼 31→43→31°C | 기존 팔로워 보드 한 개만의 고장으로 설명하기 어려움 |
| 교체 보드 유지, 리더 USB 선/Jetson 포트로 변경 | 손목 29→39/38→29°C, 그리퍼 31→45→31°C 및 32→46/47/42→32°C | 기존 USB 선 또는 Jetson USB 포트 하나만의 문제로 설명하기 어려움 |
| 이전 손목·그리퍼 2축 분리 구성 | 손목 29~30°C, 그리퍼 30~36°C, 큰 급변 미재현 | 연결 구성에 따른 차이. 짧은 검사이므로 정상 확정은 아님 |

각 6축 비교는 20초 프로필 3개를 완료했다. 옆 출력·교체 보드·교체 USB 각각 READ 원문 11,244쌍(6축 응답 확인 12쌍 포함)을 검산했다. 마지막 USB 비교는 케이블과 Jetson USB 포트를 함께 바꿨으므로 케이블만 바꾼 실험으로 쓰지 않는다.

프로필은 ① 6축의 전압+온도 30Hz ② 그리퍼 전압+온도 180Hz ③ 그리퍼 전압→온도→전압 60Hz다. 별도로 토크 OFF를 계속 감시했다. 표의 급변은 분석용으로 중앙값+8°C 이상인 표본을 센 것이다. 이 기준은 55°C 보호 조건을 변경하거나 높은 값을 버리는 필터가 아니다.

## 원문과 전압 대조

마지막 USB 비교에서 송수신 READ 11,244쌍의 ID·길이·상태·체크섬·데이터 바이트를 다시 검산했다. 오류 0회였다. 예를 들어 손목의 29→39→29°C는 정상 형식의 다음 응답에 실제로 들어 있었다.

```
29°C: ff ff 05 04 00 7a 1d 5f
39°C: ff ff 05 04 00 7a 27 55
29°C: ff ff 05 04 00 7a 1d 5f
```

세 응답의 보고 전압은 모두 12.2V다. 분리 읽기의 그리퍼 43°C 앞뒤 보고 전압은 12.3V/12.2V였다. 다만 다른 시점의 보고 전압에는 10.6V까지 내려간 표본도 있었다. 모터 내부 전압 측정도 같은 장치의 보고값이므로, 이를 독립 측정한 실제 전압 강하나 어댑터 불량의 증거로 확정하지 않는다.

순간적으로 상승했다가 다음 표본에서 원래 값으로 돌아오는 패턴은 실제 발열보다 측정·응답 이상을 의심하게 한다. 이것만으로 이전 live의 모든 57/62/81/84°C를 오독이라고 판정하거나 실제 과열을 배제할 수는 없다. 유효 체크섬도 전기적 잡음 가능성을 완전히 배제하지 않는다.

## 아직 분리되지 않은 원인

- 같은 12V 2A 어댑터와 전원 분배/접지 경로.
- 6축 연결에서만 달라지는 배선·커넥터·모터 수·전기적 부하.
- 개별 모터 또는 공통 서보 펌웨어의 온도/전압 측정 처리.
- 동일 종류 제어보드의 공통 특성. 보드 두 개에서 재현됐다는 이유로 보드 종류 전체를 배제하지 않는다.

사용자에게 정상 비교용 12V 전원과 테스터기가 없으므로 전원을 독립적으로 확정·배제하는 검사는 아직 못 했다. 어깨 모터 쪽의 빼기 어려운 커넥터는 건드리지 않았다. firmware 교체·ID 변경·보정·PID·가속도·토크·목표 쓰기는 모두 NOT_RUN이다.

## 검사 종료 시점과 임시 배선

마지막 검사 종료 시 토크는 6축 모두 0, 상태 모두 0이었다. 온도는 순서대로 29/30/29/29/29/32°C, 보고 전압은 12.2/12.1/12.2/12.2/12.2/12.3V였다. 포트는 닫혔고 `sudo fuser`는 exit 1·출력 없음으로 비점유를 확인했다. LeLab inactive, Astra 브리지 active였다.

현재는 원래 리더 보드에 리더 USB와 팔로워 6축 3핀선, 팔로워용 12V가 연결된 비교 구성이다. 리더암의 3핀·5V는 분리 상태다. 이 상태에서 LeLab을 시작하지 않는다. 사용자에게 시험 보드의 12V만 분리하도록 요청했으며, DC OFF 확인 전에는 USB·3핀 복원을 지시하지 않는다. 현행 VLA의 follower 포트 설정은 원래 팔로워 보드 `5AE6058306` 그대로이고 바꾸지 않았다.
