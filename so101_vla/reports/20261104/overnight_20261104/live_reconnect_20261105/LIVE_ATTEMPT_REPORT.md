## 차단과 다음 작업

1. 기존 사전검사에서 LeLab active로 차단됐다. LeLab 종료 시 모터 동작 여부를 확인하지 않은 채 서비스를 자동 중단하지 않았다.
2. 무인 읽기 프로파일의 토크 감지 중단 기록은 유지했다. 현장 입회용 확인/재무장 절차가 구현·검증된 상태는 아니다. 파일을 지우는 방식으로 우회하지 않는다.
3. 기존 v4는 예외 종료 시 Goal_Position HOLD 쓰기가 OFF 토크를 다시 켤 수 있으며, 동기 GPU 추론 중 모터 안전 감시 공백이 있다. `LIVE_STATIC_REVIEW.md`의 파일·줄 근거 참조. 이 경로를 실제 실행하지 않았다.
4. v5는 순수 수치 제안 모듈이며 실제 모터 실행기가 아니다. mock RobotController 통합 역시 실물 backend가 아니다. 이를 live 준비 완료로 보고하지 않는다.
5. 다음 소프트웨어 작업은 v4를 별도 현장용 실행기로 보완하는 것: 오류 시 무조건 Goal 쓰기 제거, serial 단일 소유를 유지한 추론/안전 감시 분리, 명시적 현장 재무장과 중단 처리 모의 검증. 기존 gates를 유지해야 한다.
