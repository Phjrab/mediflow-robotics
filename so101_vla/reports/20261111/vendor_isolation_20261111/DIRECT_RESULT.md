# 그리퍼 직결 온도 비교 결과

2026-11-11. **직결 상태에서는 30/180/360Hz 검사 모두 정상 완료했고,5,703개 온도 응답이33~36°C였다. 기존53°C 급변은 이번 표본에서 재현되지 않았다.** 목표·토크·설정 레지스터 쓰기0회. 55°C 중단 조건과 수신 검증은 그대로다. 온도 문제가 완전히 수리됐거나 특정 케이블이 고장이라고 확정하지 않는다.

## 연결과 실행

운영자가 DC OFF 상태에서 보드→첫 어깨 연결을 분리하고,그리퍼 선의 손목 쪽 끝을 같은 보드 포트로 옮겨 보드→그리퍼 ID6만 연결했다. 운영자의 DC ON 확인 후 읽었다. 다른5축은 물리적으로 보드와 분리된 상태이며 읽지 않았다.

동일한 제조사 C++ 파서/읽기 어댑터 `~/vendor_temp_isolation_20261111/vendor_temperature_isolation_ready`를 사용했다. 전송은 ID6의 READ40/63,폭1만 허용된다. LeLab inactive·포트 비점유 확인 후 각 단계를 별도 프로세스로 실행했고,모든 단계는 exit0/토크읽기0이었다.

|---|---:|---:|---:|---:|---:|
| ID6만30Hz |10초|301|34~34°C|34°C|0|

첫 온도 읽기를 포함해 각 루프보다1개 많은 표본이다. 이상값 분류는 저장 로그 비교용이며 runtime 온도 필터나 중단 임계 변경이 아니다.
