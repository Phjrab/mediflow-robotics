# 팔꿈치 쪽 비교를 먼저 진행

2026-11-12 운영자 요청으로 순서를 변경했다. 손목·그리퍼 두 모터 측정은 아직 NOT_RUN이며, 제어보드에서 팔꿈치 쪽 체인으로 연결하는 비교를 먼저 준비한다. 기존 ISOLATION_STATE.md와 TWO_NODE_PREPARATION.md의 물리 상태는 과거 상태이며 아래 최신 진술을 우선한다.

## 최신 확인된 상태 — 운영자 진술

- DC OFF. USB는 유지. 목표·토크·설정 쓰기를 승인받은 단계가 아니다.
- 원래 어깨–제어보드 선은 제어보드 끝만 빠져 있고 어깨 끝은 그대로다.
- 그리퍼–손목 선은 손목 끝이 빠져 있고 그리퍼 끝은 그대로다.
- 팔꿈치–손목 선의 원래 손목 끝을 제어보드에 꽂았다.
- 같은 선의 팔꿈치 끝도 현재 빠져 있다. 제어보드 쪽은 그대로 꽂혀 있다.
- 사진에서 커넥터 근처 흰 선의 급한 굴곡을 봤다. 구리 가닥 노출 또는 완전 절단은 명확하지 않다. 내부 단선 및 압착 상태는 UNVERIFIED. 추가로 당겨 검사하지 않는다.

## 다음 물리 작업 — 아직 완료 확인 전

현재 제어보드에 연결된 선의 빠진 반대쪽 끝을 원래 팔꿈치 단자에 다시 꽂는다. 제어보드 끝과 다른 선은 그대로 둔다. 이로써 제어보드 → 팔꿈치 쪽 체인이 된다. 손목·그리퍼 쪽은 연결하지 않는다. DC OFF를 계속 유지하고 연결 완료를 확인한 뒤 다음 단계를 안내한다.

사용자의 팔꿈치·손목 명칭만으로 실제 모터 ID 집합을 확정하지 않는다. 연결 ID는 UNVERIFIED이며 이후 전원 ON 확인과 읽기 전용 통신으로 확인해야 한다. 기존 ID5·6 전용 바이너리를 이 구성에 그대로 실행하지 않는다.

## 측정 조건

레지스터 READ만 허용하고 목표·토크·설정 쓰기는 0회로 유지한다. 토크 ON, 55°C, 상태/응답 이상에서 중단하는 기존 규칙은 유지한다. 연결 모터 수, 케이블 경로, 전원 부하가 함께 바뀌므로 결과만으로 특정 모터·선·전원 불량을 단정하지 않는다.

이 문서 작성 시 SSH 접속, 장치 접근, 실제 측정은 NOT_RUN. 새 배선 완료 및 DC ON은 확인받지 않았다.
