# 정렬 후 화면·모델 재확인 — 2026-11-16

**카메라 정렬은 통과다. 지금 구도를 유지하고 더 옮기지 않아도 된다.** 수직1.0px, 사선8.57px로 목표20px 이내이며 둘 다 고정판 마커4/4개가 보인다. 실제 사진에서도 기준판·바구니·약통 배치가 학습 화면에 가까워졌다.

모델 예측 비교까지 조건을 모두 통과한 것은 아니다. 첫50액션의 팔꿈치 오차가 홈 기준3.61°로 같은 홈/학습 영상의2.35°보다 크다. 단, 기준 녹화 첫50프레임은 대부분 대기인데 정렬 후 모델은 더 일찍 동작하려 하므로, 이 차이만으로 정렬 실패나 실제 집기 실패를 뜻한다고 판정하지 않는다. 새 live/녹화 재생은 실행하지 않았고, 이번에는 live 명령을 발급하지 않았다.

## 모델만 실행한 비교

640×480 원본 RGB를 다시 저장해 사용했다. 화면에 그린 반투명 참조/윤곽은 입력하지 않았다. 실제 모델·저장 processor·학습 task를 그대로 사용하고, 같은3개 seed(101/102/103)로6조건 총18회, 매회50×6 목표를 예측했다. 장치 접근을 audit hook으로 차단했고 모터 쓰기0회다.

LeLab에 새 관절 방송이 없어 **현재 로봇 state는 측정하지 않았다.** 다음 입력을 명확히 구분했다.

- `fixed_previous_home_read`: 11/15 읽기 전용으로 측정한 홈 근처6축 값. 정렬 전후 영상만 바꾸는 비교에 고정했다.
- `nominal_home`: 공통 config의 홈 평균. 현재 관절 실측값이 아니다.
- `training_episode_start`: 기준93번 녹화 첫 state.

정렬 후 모델은 집기 자세 쪽으로 팔꿈치를 내리는 목표를 더 크게 낸다. 이는 실제 팔이 그만큼 움직였다는 뜻은 아니다. 또한 움직임이 커졌다고 정확도/집기 성공이 입증된 것은 아니다.

녹화 첫50프레임의 팔꿈치 action 범위는96.44~97.41°뿐이며, 마지막은96.44°다. **대부분 출발 전 대기인 구간과 더 일찍 출발하는 예측을 같은 시각으로 비교하므로**, 카메라 개선 후에도 첫50 MAE가 커질 수 있다. 따라서 단순 MAE 상승을 카메라 정렬 악화로 판단하지 않는다. 같은 시각 비교 수치를 줄이려고 정답 궤적을 바꾸거나 시간축을 몰래 이동하지 않았다.

## 집기 시점·다음 판정

첫50예측은 모델 시간1.667초다. 기준93번의 집기 후보는181프레임(6.03초)이며 당시 그리퍼 오차1.06점, 이전 최대10.81점은 blue115의168프레임(5.6초)에서 측정한 값이었다. 이번 그리퍼 첫50 MAE0.34점을10.81점과 비교해 집기 오차가 줄었다고 주장할 수 없다. 실제 집기는 미확인이다.

정렬 기준은 통과했으므로 카메라를 계속 미세 조정할 필요는 없다. 다만 요청한 모델 비교 조건(첫50의 팔꿈치 오차가 약2° 수준)에 충분히 일치한다고 판정하지 않아 live 명령은 보류했다. 다음 소프트웨어 검토 대상은 출발 대기 시간 차이와 모델 예측 변동이다. 추종 문제인지 판정할 새 실기 로그는 이번에 만들지 않았다. 안전 검사·속도·모델 설정을 바꿔 수치를 맞추지 않았다.
