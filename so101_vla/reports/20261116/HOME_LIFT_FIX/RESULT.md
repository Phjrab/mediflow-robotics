# 어깨 들기 홈 수렴 수정 — 2026-11-16, 11-18 재개

**홈 허용 기준을 넓히지 않고, 어깨 들기의 안정된 잔차만 작은 목표 보상으로 줄이는 수정과 모의 검증을 완료했다. 실제 모델·녹화 프레임·가짜 서보로 180.02초 가상시간 실행도 통과했다. 11/18 카메라 3대의 밝은 영상이 다시 확인됐으며, 실제 카메라·모델 180초 dry-run은 진행 중이다. 수정 후 실물 홈 수렴과 약통 집기는 미검증이다.**

이 문서는 11/18 재접속 작업 중 확보된 로컬 증거와 총괄이 확인한 현재 카메라 측정을 기준으로 작성했다. 실제 카메라 dry-run의 최종 결과와 커밋 결과는 총괄이 확인 후 추가한다. 이 작업에서 실제 모터 접근·쓰기·live 실행은 하지 않았다.

## 문제와 수정

직전 실기 `runs/20261116_200615`는 어깨 들기의 홈 목표 842틱에 대해 실제 위치가 856~857틱으로 남았다. 홈 시도 3회의 잔차는 +14/+15/+14틱이었다. 온도나 통신 중단이 아니라 홈 수렴 실패로 정책 0스텝에서 끝났다. 이 로그만으로 게인·중력·데드존·접촉 중 물리 원인을 확정하지 않는다.

기존 코드는 재시도마다 같은 842틱을 보냈다. 또한 재시도 궤적을 실제 위치에서 다시 시작하여, 직전 명령보다 목표를 되돌리는 구간이 있었다. 이를 다음과 같이 변경했다.

- 판정 기준 홈 목표는 **842틱 그대로**다. 팔 관절 ±6틱, 그리퍼 ±2점, 0.5초 안정 기준도 그대로다.
- 어깨 들기만, 마지막 0.5초 실제 위치 변화가 2틱 이하이고 표본 간격이 기존 신선도 기준 이내일 때 목표 보상을 허용한다.
- 재시도당 최대 8틱, 합계 최대 16틱(약 1.41°)이다. 가동범위 801~3113틱 안에서만 보낸다.
- 재시도는 **직전 전송 목표에서** 저속 minimum-jerk로 이어진다. 허용 속도는 기존 `10°/s × speed`이며 기본 0.33배에서 연속 궤적 기준 3.3°/s다. 정수 틱 전송에는 양자화가 있다.
- 위치가 움직이는 중이거나 표본이 오래됐으면 보상을 누적하지 않는다. 3회 안에 원래 홈 기준을 충족하지 못하면 HOLD한다.
- `startup_home_trim`, `startup_home_attempt/result`, `startup_ready`에 원래 목표·실제 전송 목표·보상·잔차를 나눠 기록한다.

온도·상태·통신·실제 위치 범위·Ctrl+C 보호, 팔꿈치 목표 상한, 그리퍼 열림 보호는 변경하지 않았다. 보정 파일·P/I/D·가속도·학습 데이터·모델 원본을 수정하지 않았다. 집기 구간 오른쪽 +6틱 설정도 유지한다. 홈 명령 보상을 정책 전체에 추가하는 변경은 아니다.

## 변경 파일과 보존

- `live/live_start.py`: 안정 잔차 기반 홈 명령 보상과 재시도 연속성.
- `live/config.yaml`, `live/config_runtime.py`: 어깨 들기 한정 보상 설정 및 범위 검증.
- `sim/test_home_trim.py`: 독립 모의 테스트 12개.
- `analysis/replay_home_lift.py`: 수정 전후 가짜 서보 비교.
- `analysis/home_lift_dry.py`: 실제 모델·카메라와 가짜 모터, serial 차단, 분리된 관제 출력.
- `analysis/home_lift_recorded.py`: 저장된 학습 프레임·실제 모델·가짜 서보의 가상시간 검증 도구.

기존 실기·HOLD·실패 dry-run·초기 테스트 실패 기록은 보존했다. **현재 이 수정의 Git 커밋은 아직 작성하지 않았다.** 확인된 커밋 번호와 배포 영수증은 총괄 최종 기록에 추가한다. push하지 않았다.

11/16 최초 작업은 사용량/승인 처리 오류로 중단되었고 11/18 재개했다는 총괄 작업 이력이 있다. 이를 로봇 안전 검사 실패나 모의 테스트 실패로 혼동하지 않는다. 중단 이후의 경과 시간은 실제 검증 실행 시간과 구분한다.

## 남은 확인

1. 진행 중인 실제 모델·실제 카메라 180초 dry-run 최종 결과 확인.
2. 최종 소스·보정/모델 해시·커밋·서비스 복구 확인 기록.
3. 사용자가 현장에서 실행하는 다음 live에서 실제 어깨 홈 수렴과 집기 성공 확인.

현장 실행을 재개하는 명령은 위 검증이 끝난 뒤 총괄이 제공한다. 이 문서는 live 완료나 집기 성공을 선언하지 않는다.
