# ACT-C 5초 실패 및 10초 재시험 전 진단

> 2026-10-01 정정: 사용자가 확인한 실제 클래스는 A=큰 약통/큰 바구니,
> B=중간, C=작은 약통/작은 바구니다. 이 문서의 기존 A/C 해석은 반대였으며,
> A와 C를 바꾸라는 이전 배치 지시는 폐기한다. 아래 색상/좌우 비교는 영상의
> 외형 순서 기록일 뿐 A/B/C 클래스 매핑으로 사용하면 안 된다.

## 결론

현재 상태에서 10초 물리 테스트를 실행하면 안 된다. 5초 테스트의 떨림은 단순히 시간이 짧아서가 아니라, 현재 시작 자세와 작업대 배치가 C 학습 데이터의 시작 분포에서 벗어난 상태에서 ACT가 과격하고 불연속적인 100-action chunk를 예측한 결과다.

로봇 연결 없이 수행한 오프라인 검증에서 10,000-step 모델은 현재 카메라 화면과 추정 관절 상태에 대해 3.33초짜리 첫 chunk 동안 다음 범위를 예측했다.

- lift 범위: 약 73.1도
- elbow 범위: 약 90.7도
- chunk 안의 최대 연속 변화: 약 11.0도
- 현재 상태에서 첫 목표까지의 최대 차이: 약 10.5도

따라서 실행 시간을 5초에서 10초로 늘리는 것만으로는 해결되지 않는다.

## 현재 장면과 학습 시작 장면의 차이

- C 학습 시작 영상 60개에서 바구니는 천장 수직 카메라 기준으로 항상 `갈색/분홍(왼쪽) - 초록(가운데) - 파랑(오른쪽)` 순서다.
- 현재 캡처에서는 `파랑(왼쪽) - 초록(가운데) - 갈색/분홍(오른쪽)`으로 좌우가 바뀌어 있다.
- 학습 시작 영상에서는 그리퍼가 작업판 위쪽 대기 위치에 있지만 현재는 약통 바로 위까지 내려와 있다.
- 현재 손목 카메라에는 학습 시작 영상에 없던 노란 물체가 그리퍼 사이에 보인다. 그리퍼를 빈 상태로 만들어야 한다.

## 시작 관절 자세

60개 C 에피소드의 시작 자세 범위와 5초 시험 시작 추정값은 다음과 같다.

| 관절 | 학습 시작 최소 | 학습 시작 중앙값 | 학습 시작 최대 | 시험 시작 추정 |
|---|---:|---:|---:|---:|
| pan | -18.07 | -5.54 | 5.85 | -10.59 |
| lift | -98.77 | -98.55 | -98.24 | -96.84 |
| elbow | 89.27 | 89.80 | 91.74 | 96.57 |
| wrist_flex | 64.66 | 71.25 | 72.57 | 57.71 |
| wrist_roll | -20.79 | -12.44 | -2.59 | -11.90 |
| gripper | 1.41 | 2.33 | 8.94 | 5.88 |

lift, elbow, wrist_flex가 학습 시작 전체 범위 밖이다. 특히 wrist_flex는 중앙값보다 약 13.5도 낮다.

## 체크포인트 비교

저장된 6개 에피소드의 3개 시점, 총 18개 상태로 1,000~10,000-step 체크포인트를 모두 오프라인 평가했다.

- 10,000-step: 기록된 정답 동작과의 평균 RMSE 6.27도로 가장 낮았지만, 현재 장면에서는 가장 큰 동작 범위(lift 73도, elbow 91도)를 냈다.
- 9,000-step: 평균 RMSE 6.50도, 현재 장면 최대 연속 변화 7.14도.
- 7,000-step: 평균 RMSE 7.08도, 현재 장면 최대 연속 변화 9.67도.
- 1,000-step: 현재 장면에서는 거의 움직이지 않아 부드럽지만 평균 RMSE 18.63도로 작업을 학습하지 못한 모델이다.

즉 예전 체크포인트로 바꾸는 것만으로 해결되지 않는다. 10,000-step 모델이 과적합되어서 생긴 단순 문제도 아니다.

## 다음 10초 시험 전 필수 순서

1. 기존 색상 기준 재배치 지시는 폐기한다. 사용자 확인 기준인 A=큰 것, B=중간, C=작은 것을 적용한 수정 가이드(C/B/A 열)를 사용한다.
2. 그리퍼에서 물체를 빼고 비운다.
3. 리더암/수동 조작으로 follower 시작 자세를 학습 중앙값 부근으로 맞춘다. 특히 lift 약 -98.5, elbow 약 89.8, wrist_flex 약 71.3을 우선 맞춘다.
4. 세 카메라를 다시 캡처하여 학습 시작 화면과 비교한다.
5. 같은 오프라인 chunk 검사를 다시 실행한다.
6. 오프라인 결과가 정상화되고 사용자가 전원 차단 준비를 다시 확인한 뒤에만 10초 감독 시험을 실행한다.
