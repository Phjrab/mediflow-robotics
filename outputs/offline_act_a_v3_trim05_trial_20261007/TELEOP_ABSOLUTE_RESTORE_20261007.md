# 텔레옵 절대 자세 추종 원복

2026-10-07 KST. 사용자 요청에 따라 시작 위치 차이를 유지하는 상대 추종을 제거했다. 모델 가중치·데이터·캘리브레이션 파일은 변경하지 않았다. 로봇 동작은 실행하지 않았다.

## 변경 전과 후

이전 계산은 `팔로워 시작값 + 현재 리더값 - 리더 시작값`이었다. 리더만 원위치로 돌려도 팔로워가 원위치가 되지 않고, 켠 순간 두 팔의 차이를 계속 유지했다. 이는 기본 자세를 인식하지 못해서가 아니라 제어 방식의 문제였다.

새 방식은 시작할 때만 약3초의 smoothstep 보간으로 `팔로워 시작값 → 현재 리더 관절값`을 명령한다. 시작 정렬 중에는 몸통 관절 명령당5도, 그리퍼 명령당2정규화 단위로 제한한다. 이 값은 초당 속도나 인증된 안전 범위가 아니다.3초 이후에는 실제 팔로워와 리더 차이가 몸통 각 관절4.1도 이내, 그리퍼5단위 이내인지 확인한다. 조건이 충족되면 기존 직접 추종 설정(몸통360도/그리퍼100단위 명령당 상한)으로 전환하고, 이후 목표는 리더의 절대 관절값이다. 영구적인 시작 오프셋을 남기지 않는다. 그리퍼 목표는0–100 정규화 범위로 자른다.

시간이 지났다는 이유만으로 직접 추종에 진입하지 않는다.15초 안에 정렬 조건을 충족하지 못하면 종료한다. 정렬 중 중단/오류는 현재 관절 유지 명령을 시도하고 토크 해제 없이 연결을 닫는다. 읽기/명령 실패 시 기존 목표/토크를 유지하며 복구 경고를 남긴다. 이 경우 완전 정지는 보장하지 못하고 모터는 계속 전원이 걸릴 수 있다. 물체 접촉 감지·충돌 회피·기계식 브레이크는 구현하지 않았다.

정렬 완료 후의 일반 텔레옵 종료는 기존 동작(토크 해제)을 유지한다. 기존180초 세션 종료도 유지한다. 따라서 정상 종료/전원 상실 때 중력에 의한 처짐 가능성까지 해결한 것은 아니다. 새 시작 방식은 두 팔이 가까운 자세이고 이동 경로가 비어 있을 때 감독하에 확인해야 한다. 리더를 움직이지 않고 시작 정렬을 관찰하고, 그 다음 작은 움직임으로 검증한다. 책상 접촉 뒤 집게/관절의 휨·걸림 확인이 먼저다.
