# MediFlow VLM v4 재학습 결과 (2026-09-25)

## 결론

최신 검수 승인본으로 Qwen3-VL-2B-Instruct 4-bit QLoRA 학습을 완료했다. 학습과 추론은 정상 종료됐지만, 격리 테스트에서 약 C를 한 번도 예측하지 않았고 파지 부위를 111장 모두 `body`로 예측했다. 따라서 이 어댑터는 실제 로봇 분류나 동작에 사용하면 안 된다.

로봇 제어, calibration, ArUco, Depth, 카메라 설정은 실행하거나 변경하지 않았다. Jetson의 원본 촬영 데이터도 수정하거나 삭제하지 않았다.

## 학습 조건

- 기반 모델: `Qwen/Qwen3-VL-2B-Instruct`
- 방식: NF4 4-bit QLoRA, LoRA rank 16
- GPU: NVIDIA GeForce RTX 3060 12GB
- 학습: 3 epoch, 141 optimizer step
- 학습 시간: 약 15분 35초
- 검증 손실: 4.438 → 4.430 → 4.430
- 출력 필드: `medicine_id`, `orientation`, `target_bin`, `grasp_region`

## 격리 테스트 결과

테스트 111장과 해당 촬영 세션은 학습·검증에 사용하지 않았다.

| 지표 | 결과 |
|---|---:|
| JSON 정상 출력 | 111/111 (100%) |
| 4필드 전체 정답 | 8/111 (7.2%) |
| 약 종류 정확도 | 26/111 (23.4%) |
| 자세 정확도 | 47/111 (42.3%) |
| 목표 통 정확도 | 26/111 (23.4%) |
| 파지 부위 정확도 | 68/111 (61.3%) |

예측 분포:

- 약 종류: A 29장, B 82장, C 0장
- 자세: upright 82장, fallen 29장
- 파지 부위: body 111장, lid 0장, unknown 0장
- 잘못된 목표 통 비율: 76.6%

카메라별 4필드 전체 정답률은 Astra 0%, RealSense 50%, video4 0% (표본 1장), video6 2.4%였다. RealSense 결과는 테스트 12장뿐이므로 일반화 성능으로 단정하면 안 된다.

## 판단

데이터 수는 이전 382장에서 585장으로 늘었고 약 종류와 자세 분포도 비교적 균형적이지만, 현재 학습 방식은 여전히 다수 출력으로 붕괴했다. 단순히 epoch를 더 늘리는 것은 해결책이 아니다. 다음 학습에서는 다음을 우선 검토해야 한다.

1. 약 종류·자세·파지 부위를 한 번에 생성하는 방식 대신 필드별 분류 헤드 또는 단계별 모델로 단순화한다.
2. `lid`와 `unknown`, 약 C 조합을 균형 샘플링하고 배치별 클래스 균형을 강제한다.
3. 실제 추론 카메라를 우선 고정하고 카메라 도메인을 분리해 평가한다.
4. `before_grasp`에서 파지 부위가 보이지 않는 경우를 `unknown`으로 엄격하게 처리한다.
5. 최종 테스트 세트는 모델 선택에 사용하지 않고 유지하며, 검증 세트에 필드별 정확도와 조기 종료를 추가한다.
