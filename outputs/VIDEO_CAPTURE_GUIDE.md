# SO-101 영상 데이터 촬영 안내

촬영 페이지: `http://127.0.0.1:8011/`

## 영상 하나 촬영하기

1. 촬영할 카메라를 고릅니다.
2. 약통 종류, 약통 상태, 권장 집기 방법 등 위쪽 라벨을 선택합니다.
3. `영상 녹화 시작`을 누릅니다.
4. 동작을 진행하면서 정확한 순간에 아래 버튼을 누릅니다.
   - `접근 전 표시`
   - `접촉 순간 표시`
   - `파지 완료 표시`
5. `영상의 최종 결과`에서 성공/실패/사람 개입/미기록을 고릅니다.
6. `녹화 종료 및 저장`을 누릅니다.

영상 하나마다 MP4 한 개와 학습용 핵심 프레임 3장이 저장됩니다. 표시 버튼을 빼먹으면 영상의 15%, 50%, 80% 시점에서 자동으로 보완되지만, 직접 표시하는 편이 더 정확합니다.

## 촬영 원칙

- 영상 하나에는 집기 동작 한 번만 담습니다.
- 기본 녹화는 10 FPS, 최대 30초입니다.
- 연속으로 거의 같은 동작만 반복하지 않습니다.
- 영상마다 약통 위치, 회전, 거리, 조명, 배경, 접근 방향을 바꿉니다.
- 실제 추론에 사용할 카메라를 우선적으로 사용합니다.
- 촬영 페이지는 카메라 프레임만 저장하며 로봇 제어 명령을 보내지 않습니다.

## 저장 구조

```text
data/pilot/
├── images/scene_XXXXXX.jpg
├── videos/trial_XXXXXX.mp4
├── annotations.jsonl
├── trials.jsonl
└── session.json
```

영상에서 생성된 세 핵심 프레임은 같은 `trial_id`를 갖습니다. 학습 데이터로 가져올 때 같은 영상의 프레임은 하나의 세션으로 묶이므로 학습/검증/테스트 사이에 나뉘지 않습니다.

## 검수

학습용 컴퓨터로 동기화한 뒤 가져오기 작업을 실행하면 검수 페이지에서 추출 프레임과 원본 영상을 함께 볼 수 있습니다. 각 프레임에는 영상 내 시점과 직접 표시/자동 추출 여부가 표시됩니다.

## 현재 적용 상태

- Jetson 촬영 서버: 8011에서 새 버전 실행 중
- 손목/Astra/RealSense 카메라: 연결 확인 완료
- 기존 사진 데이터: 변경 없음
- 로컬 테스트: 촬영 서버 14개, 학습·검수 도구 11개 통과
- 실제 로봇 동작: 실행하지 않음
